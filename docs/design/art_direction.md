# 《红烛无声》人物与场景美术准备

日期：2026-10-25。用途：为场景、人物、道具图片生成建立统一依据。本文件区分剧本事实与美术建议；当前采用的素材见第8节。

## 1. 依据与适用范围

- 剧情、人物出场、时段和分支以 [mini_script.md](../../story/mini_script.md) 为主。
- 人物衣着、动作和表演可补充参考 [script.md 的人物与画面基准](../../story/script.md#人物形象与对白表演)，与浓缩版冲突时以浓缩版为准。
- **美术主参考以用户提供的四张截图为准**，归档与逐图分析见 [用户风格参考](../../assets/references/style_reference/README.md)。生图时直接提供这些图像，并结合第8节当前素材保持人物与空间连续。
- 本稿出现的年龄、具体职业、脸型、发型和体型，除明确标为剧本已有者，均是待定的美术建议。

## 2. 美术风格

目标概括为：**写实比例的二维线描叙事游戏画面，清楚轮廓、概括色块、少量柔和渐变和轻纸质感；日常人物在固定镜头里逐渐显出不安。**

| 维度       | 制作要求                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| 人物脸部   | 普通人的个体差异，眼鼻嘴结构由线与少量阴影交代，表情克制且可辨           |
| 轮廓与体积 | 人物、衣领、袖口、手和道具由清楚的深色细线组织，体积保持概括             |
| 上色       | 大色面为主，少量分层阴影与柔和过渡                                       |
| 表面纹理   | 材质用颜色、边线和少量局部纹理提示，把细节留给剧情物件                   |
| 色彩与光照 | 随场景使用暖灰、米黄、灰绿，夜景可有明显青绿暗部与橙暖亮部；颜色关系清楚 |
| 镜头与姿态 | 接近固定舞台上的人物演出；中近景可读，空间层次清楚，前景可遮挡或虚化     |

参考中的略带僵硬感来自克制表情、简化塑形和演出姿态，不等于让所有角色面瘫、故意变丑或提前露出恶相。截图中的旧照片感也不是在每个物体上增加破损。

| 项目   | 生成方向                                                                   |
| ------ | -------------------------------------------------------------------------- |
| 人物   | 普通人的五官、体型和少量主要衣褶；清楚细线与概括上色统一；小头像也可辨     |
| 建筑   | 中式木构、灰瓦、木格窗、院落与回廊；先有可信的居住和接待功能               |
| 材质   | 用概括色面区分木、铜、棉布、纸与墙；少量磨损集中在常触碰的位置，不逐处描纹 |
| 氛围   | 安静、停顿、遮挡、熟悉细节的轻微偏差；恐怖逐层显露                         |
| 可读性 | 门闩、烛芯、私人物件、呼吸和影子所在区域保留细节，不能全部压黑             |
| 红色   | 主要落在红烛、红蜡与少量印记上，避免整屏红光抢走身份线索                   |

寺庙白天仍接待游客，房间窗纸洁白、有人维护。旧与危险不等于到处坍塌、长满霉菌或贴满符咒。建筑细节宜先统一为一套中式寺院语言，再决定具体地域，不混入西式教堂、日式神社或仙侠宫殿造型。

完整版的雨夜青灰与琥珀灯光可沿用到夜间；浓缩版开场必须是晴天下午，不继承暴雨、湿透衣服、红伞和雨水满地的开场状态。

| 时段       | 光色与情绪                                           | 连续性要求                             |
| ---------- | ---------------------------------------------------- | -------------------------------------- |
| 抵达的下午 | 低饱和日光、浅金树影、灰瓦与淡青天空；正常的周末旅行 | 怪异处少量埋线，人物自然放松           |
| 晚膳与入夜 | 夕阳斜光逐渐退去，檐灯亮起，窗外转靛蓝               | 同一扇窗与同一排灯的光向连续变化       |
| 午夜       | 冷青月光与局部琥珀烛光；暗处仍有可检查的层次         | 阴影跟随真实光源，门窗与道具位置固定   |
| 假报晓     | 窗外依旧黑，缺少自然晨光                             | 不以画面提前替玩家确认已经天亮         |
| 真正天亮   | 以自然晨光恢复院落细节，金色柔和，人物疲惫           | 复用夜间的空间结构，让玩家亲眼核对变化 |

## 3. 人物身份、性格与形象

### 主角“你”

- **剧本已有**：游客，住“门”房；完整版明确不固定姓名、性别和既往身份。
- **形象方向**：以第一视角代入为主，默认不固定主角头像，首批无需主角全身立绘。
- **所需素材**：若调查动画需要，可制作持钥匙、火柴、红烛或经书的第一视角手部；袖口、手型和左右手跨镜头保持一致，默认尽量不突出年龄与性别。

### 林岚：用玩笑和拍照维持镇定的人

- **剧本已有**：女性同行、摄影爱好者，住“听”房；相机盖放在铜铃旁。具体职业与年龄未定。
- **性格分析**：说话快、善观察、愿意活跃气氛，有自己的分寸；会配合身份核验。真正害怕时先检查相机盖，把相机抱低，玩笑里开始有停顿。
- **职业建议**：视觉内容编辑，摄影是长期爱好；也可保持普通游客身份。不要仅因爱摄影就写成职业摄影师。
- **外形建议**：约25—29岁，利落的齐肩发或短发，眼神有活气；浅砂色休闲外套、普通深色长裤、舒适鞋、小型相机与固定相机带。浅砂外套与相机带来自完整版描写，其余为建议。
- **脸部辨识锚点**：较窄的椭圆脸、偏尖下巴、眉峰与眼尾略有上扬，侧分短发，神态活跃。表情变化时保留这些结构。
- **动作与表情**：平常扬一下相机、侧身看光；紧张时握紧相机带、肩膀微收，目光从镜头转到门外。
- **首批变体**：自然交谈、克制玩笑、警觉、害怕；完整站姿和看向门缝的侧身姿态。

### 周砚：习惯解释问题，也必须学会承认未知的人

- **剧本已有**：熟悉古建筑的同行，住“灯”房；修缮图折在灯座下。具体职业与年龄未定。
- **性格分析**：逻辑清楚、先看结构、遇事想找解释；害怕时会反复确认退路。可靠体现在持灯、候门和帮助观察，不替玩家给出谜底。
- **职业建议**：古建保护研究助理或修缮项目助理，能够解释兴趣和基本知识。身份无需通过工作制服表现。
- **外形建议**：约28—33岁，男性形象建议；身形偏高瘦，短发、五官收敛。深蓝休闲外衣、灰色内搭、耐走的鞋与小挎包；深蓝外衣来自完整版，其余为建议。
- **动作与表情**：低头看门轴、用手压平图纸、持灯时保持光束稳定；紧张时嘴唇微抿，先回望再说话。
- **首批变体**：平静说明、认真观察、不确定、紧张持灯；不用持续皱眉来代替性格。

### 许栀：习惯照顾别人，必要时能明确拒绝的人

- **剧本已有**：女性同行，来寺散心，住“纸”房；蓝发圈夹在《入住须知》上。具体职业与年龄未定。
- **性格分析**：细心、及时接话、先关注同伴，把自己的不舒服往后放；“我不想”说完整时显出边界。散心不等于已有疾病或确定的创伤背景。
- **职业建议**：图书编辑；这只是生活背景建议，也可不指定职业。避免为了温柔性格额外编造医护身份或悲惨身世。
- **外形建议**：约25—30岁，自然平刘海与锁骨长度中长发，头部摆正，神情温和但有清楚的目光。灰绿色长袖外衣、浅色内搭、普通长裤与帆布包；衣袖到指根、灰绿色衣服来自完整版。
- **脸部辨识锚点**：短圆脸、饱满面颊与圆下巴，较平直的眉、偏水平的眼形、短圆鼻头，嘴唇较薄、嘴角平缓。与林岚的窄脸、偏尖下巴和侧分短发形成区别，不能仅靠衣服与包区分两人。
- **道具连续性**：蓝发圈已经放到纸上时，人物头发上不能同时出现另一枚相同发圈；发型要在无该发圈时也成立。
- **动作与表情**：先回头确认别人，双手轻拢袖口；拒绝时站稳、抬眼、嘴部有明确发声姿态，避免一直缩肩流泪。
- **首批变体**：关切、轻松接话、犹豫、坚定拒绝；与林岚的脸型和发型保持明显差异。

### 陆沉 / 照尘：守着规矩，也被规矩困住的人

- **剧本已有**：在籍守夜僧，俗名陆沉、法号照尘；负责登记、门禁、钥匙与巡门。寡言、多疑，对具体责任与旧事会停顿。
- **性格分析**：一面执行害人的制度，一面用推近素饼、保护灯火等小动作保留善意；愧疚表现为犹豫和收手，不是一开始就亮明善恶立场。
- **外形建议**：约40—50岁，偏瘦、肩背因常年劳作微收，面部疲惫、目光警觉。灰褐洗旧僧衣、薄领口、布鞋、铜钥匙串和提灯；发型建议剃发或极短发，作为正式造型待定。
- **形象锚点**：剃发、疲惫而警觉的神态、洗旧僧衣、铜钥匙与提灯；沿用当前立绘的脸型、衣领和体型。
- **动作与表情**：挡住灯口，钥匙碰响后攥住，递物时停半拍；警惕、回避、短暂关切三种状态比夸张怒脸更有用。
- **首批变体**：登记桌后坐姿、提灯站姿；平静接待、审视、愧疚欲言又止。浓缩版先不制作完整版释愿高潮。

### 慧普：过度温和、过度周到的危险

- **剧本已有**：恶愿残念借皮现形的住持，背后没有正常骨肉；初见位于帘后，语气温和，不靠突然跳脸。
- **性格分析**：用照顾和承诺诱导别人同意。可怕之处是态度始终亲切，却不愿做真正解除危险的行动。
- **外形建议**：借用约60—70岁僧人外貌，剃发、平静眉眼、克制微笑；暗赭或旧褐袈裟。袈裟过于平整，袖口与下颌的皮略不合身，差异要到近处才看清。
- **揭露设计**：优先生成帘后坐影、露出袖口的手、门缝所见背面；空背与缝线在剧情要求的角度出现。初见头像不提前展示怪物结构。
- **首批变体**：温和外观设定、帘后局部、剥皮场景中的背身与手部、转身察觉。背身需与同一个人的衣褶和皮肤边界对应。

### 神公：还有活人气息的守殿老人

- **剧本已有**：守杯筊的和尚，“神公”是称呼；初见疲惫、衣领有呼吸，失败时逐渐石化。
- **性格分析**：话少、讲规矩、不替玩家作主，偶尔像嫌游客吵的老人；与慧普的主动劝诱不同，他更多等待玩家问清楚。
- **外形建议**：约65—75岁，清瘦、颧骨明显、肤色少见日光；暗灰宽袖僧衣，袖褶稳定，手指有真实的关节与停顿。
- **动作与表情**：低头看杯筊、指腹把木筊推到盘心；抬眼短答，神情疲倦但有注意力。
- **首批变体**：桌后活人坐姿、引灯站姿、局部石化、全石像。石化保持同一五官、姿势、袖褶和桌面布局，变化集中在材质。
- **版本边界**：浓缩版只有一次紧急投掷；不因参考完整版而在画面里新增三问流程。

### 换皮同伴与门外人

- 换皮者是对应同伴的外观变体；脸、衣服、相机带等不能换成另一个角色的设计。
- 第07幕门外人、第10幕室内假同伴与第11幕门外诱导要分别设计呈现角度，不能用同一张暴露怪物全貌的图覆盖所有阶段。
- 第10幕先保留熟悉外貌，仅通过呼吸、影子和略不自然的姿势制造疑点；抓脸后才出现衣领缝线等明确异变。
- 依据实际分支，三位同伴均可能需要对应变体；先锁定三人的正常形象，再从同一参考派生。
- “没有呼气雾”只有在同场正常人确有可见雾气参照时才容易读懂；正式分镜需补足参照，不能靠画师随意改变天气制造答案。
- 影子与呼吸宜独立制作，跟随场景光源组合，避免把某个光向永久画进透明人物。

### 本轮暂缓的完整版人物

白檀、顾怀山的当前异变实体、顾惟真、纪归年、沈墨、法华不在浓缩版首批独立人物立绘范围。门房寺史册若需要顾怀山旧照，可先制作一张档案插图；不等于新增当面出场角色。

## 4. 场景图片清单

十二幕不等于十二张独立大背景。建议先组织为以下八组基础空间，每组再制作必要机位、时段与状态。

| 空间               | 对应分镜               | 必要画面与状态                                | 制作重点                                                   |
| ------------------ | ---------------------- | --------------------------------------------- | ---------------------------------------------------------- |
| 山门与石阶         | 01、12                 | 晴日下午抵达、清晨离开                        | 从游客眼前看新匾与露出的旧匾，花猫、铜铃；不用鸟瞰寺院全景 |
| 登记处             | 02                     | 下午空背景、登记簿近景                        | 桌后留陆沉位置；房牌、行李、钥匙可独立增减                 |
| 东院回廊           | 02、04、07、08、11、12 | 白天、黄昏、午夜、清晨；同一布局              | 四房位置、铜铃、花瓶、烛光与出口保持连续                   |
| 斋堂               | 03                     | 夕阳空背景、桌面近景、帘后角度                | 四碗粥的对应关系可查；慧普局部独立叠加                     |
| 主角“门”房         | 05、06、07、10、11     | 环视、朝门、看窗；夜间亮烛/灭烛、假报晓、晨光 | 床、桌、门闩、烛台和窗固定；门缝观察另做主观近景           |
| 受害偏房           | 08                     | 从回廊透过半掩门看到的室内                    | 只显示主角视线内的床沿、手、皮与地面；门板遮挡可独立叠加   |
| 大雄宝殿与东侧偏殿 | 09                     | 大殿夜间接近角度、守筊桌前角度                | 长明灯与偏灯建立方向；桌、佛像和神公石化位置可对应         |
| 大巴车内           | 01、12                 | 抵达窗景、返程后视镜视角                      | 从乘客位置看到车窗或镜面；结尾旧匾只出现在实际可见的反射中 |

“听、灯、纸”房间优先制作门口与身份道具的观察视角，不必首批各做完整可探索房间。钟楼、后山只在浓缩版作为错误方向或远处封闭入口出现，暂缓内部完整场景。

生成时先锁定一张简易平面图与各机位朝向。平面图是制作参考，不直接作为上帝视角过场。门的位置、转角、神公所在的东侧和人物进出方向必须在不同图片中相容。

## 5. 道具与异常效果

| 类别         | 需要单独准备的素材                                          |
| ------------ | ----------------------------------------------------------- |
| 身份与随身物 | 铜钥匙、通行凭、念珠、残页、房牌、三位同伴的行李            |
| 身份核验物   | 相机与盖、铜铃、折叠修缮图、蓝发圈与入住须知的组合          |
| 桌面文本物   | 登记簿、寺史册、蓝封经书、施食记残页                        |
| 进食选择     | 四只可对应的粥碗、木勺、素饼、热水；粥面油花与肉纤维近景    |
| 生存物       | 红烛、烛台、火柴、手电、门闩；红烛未点燃/燃烧/熄灭/短芯状态 |
| 民俗与环境物 | 杯筊三种结果、封条、杯筊盘、猫食碟、鸟笼、花瓶及碎片        |
| 氛围与反馈   | 烛焰、烟、呼吸雾、人物影子、门板鼓起的局部、石化遮罩        |

动物优先做山门花猫与必要鸟类局部。猫叫、鸟叫、敲门、更锣和钟声需要独立声音素材；图片只呈现可见声源，不用画中文字替代听辨。

文本物生成纸张、封皮、印泥和磨损底图，精确文字由前端或排版叠加，便于保证房名、经文、警告与登记内容正确。铜钥匙、残页、未点燃红烛、念珠和通行凭已有独立正式物品图，同一高清透明原图供道具栏与详情共用；通行凭与残页分开。运行中的演示仍沿用原切图，接入时更新映射。

红烛在桌上、手中或神公处的归属与位置要明确，不能每幅场景自动出现一支。烛长与蜡泪随时间延续；火焰是正常暖色小光源，红蜡不等于把全室照成纯红。

## 6. 图片交付与一致性建议

- **角色定型图**：先为六名主要 NPC 做正面、侧面、背面或四分之三角度参考，锁定脸、发型、服装、体型和随身物。设定图只供制作，不进入游戏视角。
- **人物成品**：透明背景、完整轮廓，日常与异常状态分开；半身和全身按出场机位选择。人物单独出图后，在实际背景里核对笔触、尺寸、地面接触与光照。
- **头像**：六名主要 NPC 已有独立方形普通对话头像，沿当前立绘生成，保留五官与服装锚点。边框、底色与名字由界面提供；情绪或异常状态从同一身份参考派生。帘后初见和未看清的门外发言使用共用黑影加问号占位，保留同一个头像框；不通过后台身份改变占位轮廓或提前暴露真假。
- **背景**：沿用现有文档的16:9、优先2560×1440建议；空背景不混入 UI、字幕、头像、道具栏或不在场人物。
- **裁切**：现有界面的背景区域比整屏16:9更宽，先以实际游戏容器预览再定出图比例；关键线索远离易被裁掉的上下边缘与字幕可能覆盖的位置。
- **分层**：背景、人物、门板遮挡、道具、影子与光效按状态拆分；背景保留人物离开后的完整区域，人物使用独立透明图层。
- **时段变体**：沿同一机位参考修改光照和状态，锁定门窗、床桌、裂纹与物件位置，避免每次重画出不同建筑。
- **原图与网页图**：原图归档在 `assets/`，接入文件放 `web/public/art/`；新目录用 `lower_snake_case`。建议按 `characters/<npc_id>/`、`scenes/<scene_id>/`、`props/<prop_id>/` 分类。
- **视觉核验**：先检查轮廓、五官与道具，再放回实际画面检查大小和遮挡。推理关键细节要在正常显示尺寸下看得清，不能只在原图放大后成立。

## 7. 素材制作顺序

1. 直接使用用户提供的四张主参考与当前素材，统一线条、概括上色、脸部画法与场景色彩，再扩展批次。
2. 先定林岚、周砚、许栀、陆沉、慧普、神公六人的正常外观，再逐人制作姿态与表情；职业和年龄建议在此阶段定稿。
3. 优先做东院回廊与主角门房的干净背景，验证人物站位、烛光、门缝和身份核验细节。
4. 从同一人物和空间参考派生换皮同伴、慧普空背、神公石化等异常状态。
5. 补齐山门、登记处、斋堂、受害偏房、大殿与大巴，以及独立道具、文本底图和时段变体。

后续每次生图提示词应包含：统一画风 + 已定角色/空间参考 + 当前主角机位 + 剧情时点与情绪 + 必须出现的可见线索 + 分层与尺寸要求。具体年龄、职业与造型建议在定稿前不反写进剧本事实。
