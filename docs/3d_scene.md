# 红烛寺的实时 3D 场景

正式游戏采用原生 WebGPU，按同级 Tidewater 的场景方法制作写实地形、材质、光照和模型。运行时不依赖 Three.js；Three.js 仅用于离线读取授权 FBX，浏览器加载已打包的原生网格。

## 与参考项目的对应

| Tidewater | 当前实现 | 用途 |
| --- | --- | --- |
| Engine / GPU | scene/renderer/engine.ts | 显卡、画布、帧提交、尺寸变化与资源销毁 |
| GeoKit prepare / mergePrepared | scene/geometry | Y 轴朝上、米制几何、法线变换、统一顶点格式与合并网格 |
| GameMaterials / scene lighting | scene/renderer/scene.wgsl | 线性颜色、GGX / Lambert、粗糙度、金属度、木纹、布纹、石材与铜锈 |
| SceneRenderer / Shadows | scene/renderer | 阴影深度 pass、3 × 3 PCF、主渲染 pass、4 倍 MSAA、雾和色调映射 |
| Vendor | scene/world_character | 独立角色模型、呼吸、转头、交谈、行走、登记与用膳动作 |
| Buildings / Props | scene/world_environment、world_prop | 寺院建筑、房间、巴士与可调查道具 |

着色器噪声与材质约定按 Tidewater 改写；其 MIT 版权声明完整保留在 [tidewater_license.txt](tidewater_license.txt)。海洋模拟、船控和钓鱼玩法不属于本作场景需求。

## 保留的内容

角色姓名、身份、剧情分支、台词、云端音色、语音转写和音频播放均使用现有实现。人物采用 Microsoft Rocketbox 的解剖头部、皮肤法线、真实手部和游客服装网格，保留角色配色、僧袍与私物。三位游客有独立面孔和发型，僧人使用无帽头模；对白栏仍使用原表情头像。原开场视频与文字证据保留。

后端仍是唯一状态来源。前端从 sceneKey、shotKey、actors、flags 构建画面，不修改吃粥、投掷、生死、物品或存档。未确认门外声源不创建实体；帘后慧普只在对应镜头显示；假天亮继续使用夜间灯光。

## 分镜与交互

scene/world/placement.ts 定义米制机位和道具锚点。微光按钮通过真实摄像机投影到模型附近，使用原命令提交回合；语音无需鼠标或自由移动。调查物件会靠近模型，阅读经文和凭证保留可读文字。

寺院使用细分木构、带厚度与瓦唇的阴阳瓦和真实门窗洞口。木门包含分板、门轴、横撑和铜环；换皮者先走近关闭的门并触闩，狂躁镜头才滑开门闩、绕铰链开启门叶。大殿和偏殿使用 Minneapolis Institute of Art 的 CC0 观音扫描，保留原雕塑的脸部、盘坐、衣褶与旧彩绘，配以木石供座。山路和寺院外采用连续高度场、Poly Haven 树木、苔石、蕨类与草丛，树冠、蕨类与草叶按高度响应风场，根部保持固定。昼夜共享同一空间；红烛状态同时控制烛焰和局部光源，空满碗、碎花瓶和杯面由对应旗标控制。

人物的肘膝使用连续两关节混合变形，掌心锚点与网格同步；坐姿不缩短腿部，伏身围绕髋部旋转。登记动作通过手臂求解让笔尖落在簿册上，支撑手保持静止。用膳区分喝粥与素食餐具，抬手、入口和放下错开节奏；手持碗替代桌上的同一只碗。递烛、噤声、看帘、观察、碰门闩、抓挠与伏地按分镜触发，四句经文逐步压低抓挠幅度，石化和受害者停止活人呼吸。室内脚底采用随关节更新的局部环境遮蔽，补充方向光阴影。

转场沿用原持续时间与环境音，改用眼高摄像机推进、殿内横移、角色步态和巴士位移。主角是摄像机。减少动态效果设置下，动作直接显示稳定状态；隐藏标签页暂停绘制时间。保存、暂停或重听确认不重置演出时钟；真正改变分镜、动作、同行者或过渡类型时才重置。转场和画面不可用期间停止自动续行。

## 浏览器与资源

启动流程先完成 HTML-in-Canvas 实际绘制检查，再进行 WebGPU 三角形绘制与像素回读，全部通过后才加载游戏。没有调试参数或确认缓存旁路。GPU 失败或连接丢失会显示原因并要求重新载入。

每个画布独立拥有 device、纹理、缓冲和渲染循环，切换世界释放旧网格，组件卸载释放显卡资源。DPR 和绘制分辨率设有上限；静态几何按场景或刚性部件合并，材质参数进入顶点数据。

外部素材已转为 `web/public/art/world/` 下的固定本地文件，运行时不访问素材网站。Poly Haven 提供 CC0 植被、岩石、PBR 表面与昼夜全景天空；Microsoft Rocketbox 提供 MIT 人物网格；Minneapolis Institute of Art 提供 CC0 观音雕塑扫描。来源、授权、重建步骤与预算见 [环境素材](../assets/environment/README.md)，原图用途见 [asset_usage.md](../assets/generation/asset_usage.md)。

材质读取基础色、法线与 AO/粗糙度/金属度贴图，纹理包含 mipmap；叶片透明轮廓同时用于画面和阴影。天空随摄像机方向取样，并提供环境反射。近远树使用不同网格、共享显卡缓冲；远树不投近景阴影。阴影 pass 使用独立绑定组，避免阴影图同时被写入与采样。
