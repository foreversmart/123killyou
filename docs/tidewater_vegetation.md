# Tidewater 植被

当前山路、山门、前庭、远山与内院统一使用 Tidewater 的程序植物几何。原项目采用 MIT 许可，版权为 `Copyright (c) 2026 DRG Software Solutions LLC`；完整声明见 [tidewater_license.txt](tidewater_license.txt)，运行素材目录也保留 `LICENSE`。

## 来源与重建

```sh
node scripts/tidewater_vegetation/build.mjs ../tidewater
```

源目录参数默认同级 `../tidewater`。导出器直接调用原 `PlantGeometry.js` 的生成函数，使用原 `TreeForms.js` 与冠瓣缩放表处理四个树冠、两个灌木变体；其他网格包括棕榈、幼棕榈、蕨类、两个芭蕉变体、龟背竹、海芋、赫蕉和鹤望兰。`GrassField.js` 的原近景草格保留 448 个八叶草丛和 16 个燕麦槽内的四叶配草，提取草叶种类后形成一个 8 × 8 米草格。当前场景没有引入岛屿海岸、海燕麦或沙地匍匐藤。

输出固定覆盖 `web/public/art/vegetation/vegetation.json`、`vegetation.bin` 和 `LICENSE`。网格不减面，不改拓扑，保留法线、UV、材质与变形参数。树冠变体在 CPU 上应用原缩放与树形；棕榈和林下植物烘焙静风直立时的干冠连接位置。清单记录生成种子、源文件 SHA-256 和布局约定，正式游戏与 CI 不依赖 Tidewater 仓库存在。

全部 16 个网格为 31,510 三角形，二进制 2,916,104 字节。单树冠 1274 三角形，单灌木 110；完整草格 18,240。草叶尖端允许越过 8 米格界，布局与剔除依据各株根部，而非叶尖包围盒。

## 顶点与场景适配

每顶点 16 个 Float32，索引为 Uint32。清单偏移量以字节计，`vertexCount` 是浮点元素数，`indexCount` 是索引数。植物顶点包含位置、法线、原 `aMat.yzw`、原 `aVeg`、UV 与编码后的相位；材质编号为冠层 `100 + part`、其他植物 `120 + part`、草叶 `140`。草格元数据另保留株根 X/Z、叶片随机数、根尖比例、原精度层级及左右边坐标。

`scene/vegetation/batches.ts` 按空间区域与阴影状态合并静态植物，另保存每顶点对应的世界根部与实例种子。室外草丛逐株采样 `terrainHeight`，一株所有顶点使用同一接地高程；落在寺院铺地或盘山路面内的整株草丛被剔除。树木和林下植物通过既有道路、地形与建筑净空散布。前庭与内院沿原花坛调整实例位置和尺度，保留通路、石景与灯具。

远山复用同一套原树冠几何并关闭远景投影；没有移植原项目的岛屿散布、动态草格 LOD 或八面体远景替身。植物全部维护在独立的 Tidewater 素材库；通用库仅保留当前使用的岩石、人物、观音与建筑表面。

## 材质与慢风

`scene/vegetation/leaf_atlas.ts` 与 `leaf_shapes.wgsl` 按原 Twig / Rosette 算法生成叶簇图集，细树叶、圆叶灌木和窄叶灌木共享原轮廓。其余着色模块移植原树皮、树冠色差、叶脉、透光、羽叶切口、芭蕉裂叶、阔叶形态及草丛根尖明暗。渲染继续使用本作 WebGPU 光照、天空、雾和色调映射，整体亮度随本作昼夜场景变化。

风响应使用统一的 `time × 0.24` 时钟，即约原速四分之一。低频阵风带动树干和枝端，较细的变化带动叶片与草尖，草叶保留长度约束；根部保持在地形上。可见画面与阴影共用顶点变形，暂停时随现有场景时钟停止。改动仅作用于场景表现，不改变语音、转场、道具或存档规则。

`web/tests/tidewater_vegetation.test.mjs` 验证素材完整性、二进制边界、变体差异、根部元数据、草叶拓扑、逐株接地、道路与铺地排除，以及当前场景的植物引用。
