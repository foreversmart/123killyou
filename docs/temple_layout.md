# 红烛寺院落平面

红烛寺采用常见汉传佛寺的南向中轴布局。山门在南侧，地势向北升高；主礼佛建筑沿中轴递进，钟鼓楼和生活服务空间放在东西两翼，前后院之间用石道与回廊连接。它参考的是现实寺院的空间组织方式，不复制某一座寺院的测绘图。

```text
                               北 / 后山
        方丈院       藏经楼 / 法堂       香积厨 · 库房 · 净房
          │              │                    │
       客寮院          后院石道              僧寮
          │              │                    │
      伽蓝殿       大雄宝殿（主轴）         祖师殿
          │              │                    │
       钟楼         天王殿 / 前院            鼓楼
          │              │                    │
       客堂          登记房 · 石阶            斋堂
          └────────── 山门前院 ──────────┘
                         │
                      东南放生池
                               南 / 山路
```

3D 场景把这套平面固定在约 64 × 60 米的平台上：`x < 0` 为西翼，`x > 0` 为东翼，`+z` 指向山门。`web/src/scene/world_environment/temple_layout.ts` 是建筑名称、用途、尺寸和坐标的单一来源；`temple_compound.ts` 用它挂载可寻址建筑节点并合并静态网格；纸面地图复用同一套建筑关系。

东院客房回廊是登记室与礼佛建筑之间的实际步行通道，不把人物移动停在偏房门口：登记完成后，队伍从登记室进入回廊，沿两侧偏房前行；回廊尽头的“大殿侧门”接入大雄宝殿，山门一侧的“偏殿回廊”接入东侧偏殿与院路。两个端景由 `web/src/scene/world_environment/corridor_terminals.ts` 建模，保留木梁、灰泥、石阶、旧匾和檐灯的连续材质；偏殿端景还在门楼后接上铺地、侧墙、后墙与瓦顶，转身时不再露出天空。登记室、回廊、大殿和偏殿之间的切换仍由剧情转场控制，端景只负责在第一视角行走镜头中交代空间连接。

门房和半掩偏房共用 `room_shell.ts` 的闭合壳体：前门墙保留真实门洞，左右墙延伸到后墙，后墙和木板天花板覆盖完整视点范围；`enclosure_layout.ts` 同时提供壳体尺寸与行走边界，调查镜头和自由转身都不会把摄像机推到墙外。

建筑用途保持克制：天王殿负责入口礼佛，大雄宝殿是主殿，藏经楼/法堂位于后轴；伽蓝殿、祖师殿是两侧配殿；钟楼、鼓楼成对报时；斋堂、客堂、客寮院、僧寮、香积厨、库房和净房组成日常寺务；放生池放在山门内东南角，作为山门前院的水面参照。
