# 《红烛无声》逐场景视觉复核

这份复核以当前 `GameState.sceneKey`、`shotKey` 和 WebGPU 场景图为准。角色由第一视角镜头代表主角，已确认的 NPC 才会进入场景；对白头像仍只用于对白栏。每个场景都保持同一套米制比例、PBR 材质、阴影和灯光，避免“背景插画 + 立绘”在镜头切换时互相穿插。

## 画面之间和场景之间

- 同一场景内的 `shotKey` 变化会触发 280ms 的聚焦沉降：画面轻微从低饱和、低亮度和 1.008 倍缩放回到正常状态，给新机位一个“视线落定”的时间。`prefers-reduced-motion` 会关闭这段装饰动画。
- `travel` 和 `hall` 过渡已经有独立的第一视角移动、横向大殿通行和淡入淡出，不再叠加聚焦动画。登记到斋堂明确经过“东院回廊 → 大殿 → 斋堂”，大殿横向停留约 7 秒。
- 转场标题在画面 ready 后延迟入场、停留后淡出，避免文字先于场景出现或在场景未结束时突然消失；暂停时保留当前帧和标题。
- 旧场景的隐藏角色不会被过渡镜头揭示，死亡和重试沿原场景回到同一空间；转场期间不开放新的选择。

## 寺院空间与佛教元素

- 山门和院落使用连续围墙、台基、坡屋顶、石阶、石灯笼和入口香炉，保持“山门—前院—大殿—后院”的纵深关系。
- 大殿过渡只显示四天王、壁画和观音供座；壁画与木雕使用低饱和矿物色，瓦面、木柱、灰泥墙和石台基保持旧寺的粗粝度。
- 东院回廊的门间墙段增加六块浅浮雕式矿物颜料壁画，沿行走视线依次露出莲花座、背光、如意云和飘带细节；房牌与门洞保持无遮挡。
- 偏殿使用观音、杯筊桌、香炉、长明灯和经幡式陈设；斋堂只保留木鱼、食案、帘后灯和素食，避免把每个房间都做成佛殿。
- 客房和偷听偏房保持朴素：床、矮桌、经书、念珠、油灯、鸟笼、猫食碟和门闩磨损构成生活层，不加入会误导叙事的佛像。

## 模型来源与接入边界

运行时不从模型网站请求资源。候选模型先下载到离线工作目录，统一米制、清理层级、减面、转 GLB，再覆盖固定路径并更新素材清单。当前已核验来源见 [`assets/environment/temple_model_sources.md`](../assets/environment/temple_model_sources.md)：

- MIA 的观音、Dvarapala、Nio Temple Guardian、香炉和 Water-Moon Guanyin：CC0，可直接作为离线参考或接入候选。
- Poly Haven：CC0，继续用于瓦、木材、石材、灰泥、植被和天空表面。
- Sketchfab 的 Japanese Temple、Chinese Temple、Incense Burner：CC BY 4.0，可用于商业项目但必须保留作者、页面和许可证署名；在正式接入前重新核验 API 元数据。
- 未提供开放许可证或标记不可下载的商业模型只作为比例参考，不复制网格、贴图或下载后打包。
