# 《众誓堂·灯影寺：红烛无声》浓缩分镜脚本

> 类型：单人第一视角、古寺民俗惊悚、语音互动、生存分支。
>
> 本稿把当前 `story/base.md` 与 `story/script.md` 的人物、寺史和恶愿设定，压缩成一条“周末入住—午夜求生—五更离寺”的可制作路线。入寺时间按需求设为阳光明媚的下午；天色在晚膳后自然转暗，不改变灯影寺的既有背景。

## 一、背景与角色锚点

灯影寺旧名“明照寺”。七年前，老方丈顾怀山被寺方宣称“密室圆寂、成佛”，但寺内没有合格的验身记录；真正的故事是慧普住持留下了以肉粥、取人皮和续愿仪式维持的恶愿。皮库总账已经记到七十七名外客，今夜四名游客在登记簿上被预留为林岚78、周砚79、许栀80、主角81。吃不吃粥不会改变皮号，但吃粥会缔结“肉缘”，让夜里的声音和幻象更容易骗过人。

“守夜人”是陆沉，法号照尘。他寡言、多疑、重规矩，负责登记、钥匙和夜间巡门；他曾被慧普以“守满八十一便能救师父”束缚，所以明知寺规有问题，仍没有立刻反抗。慧普住持是恶愿残念借皮现形的主持者，背后没有正常的骨肉，只有被缝住的一层皮。偏殿的神公守着杯筊和旧规矩，不能替玩家做决定，只能给一次活路提示。

### 主要人物

| 人物      | 入住位置与可辨细节                             | 表演方向                                                       |
| --------- | ---------------------------------------------- | -------------------------------------------------------------- |
| 主角“你”  | 东院“门”房；持铜钥匙、残页、红烛、念珠、通行凭 | 只通过你的视线、声音、调查和选择推进；不能切到他人视角         |
| 林岚      | “听”房；摄影爱好者，相机盖挂在铜铃旁           | 说话快，怕时反而先检查相机盖；熟悉猫叫、拍照和同行闲聊         |
| 周砚      | “灯”房；熟悉古建筑，修缮图折在灯座下           | 习惯看门轴、梁柱和灯芯；紧张时仍试图解释结构                   |
| 许栀      | “纸”房；来寺散心，蓝色发圈夹着《入住须知》     | 先照顾别人，真正害怕时才说出“我不想”；记得入住时听过的私密短句 |
| 陆沉/照尘 | 山门、登记桌、东院回廊                         | 用短句守规矩，遇到“谁送粥、谁开门、为何不能出门”会停顿         |

| 神公      | 大雄宝殿东侧偏殿，守杯筊桌                     | 初见像疲惫的守殿和尚；掷筊后只说“命不该绝”或化作佛像           |

## 二、制作状态与道具

| 状态                  | 触发与作用                                                                |
| --------------------- | ------------------------------------------------------------------------- |
| `red_candle_lit`      | 回房后必须点燃红烛；未点燃或半夜熄灭而不续燃，怪物破门，直接进入死亡反馈  |
| `meal_choices`        | 分别记录四人吃粥、拒绝或暂缓；吃粥增加肉缘和幻听，不直接判死              |
| `meal_all_ate`        | 四人都吃粥；偷听住持时没有可依靠的真同伴，必须用猫叫或鸟叫掩护            |
| `skin_double_present` | 主角吃粥，或三名同伴都吃粥；回房后出现一个已经换皮的“同行人”              |
| `companion_present`   | 至少一名未被换皮且愿意同行的同伴进入偷听路线                              |
| `animal_call_passed`  | 玩家在花瓶声后模仿已听过的猫叫或鸟叫；输入窗口不叠人物对白                |
| `cup_jiao_rescue`     | 在大殿求神公，圣筊可被红烛带回房；笑筊/阴筊失败。主角吃粥时圣筊成功率降低 |
| `mind_script_learned` | 在房中读过《清心静神经》；只有读过才能安抚换皮同伴                        |

### 固定道具

- **铜钥匙**：陆沉登记时交给主角，钥匙柄有模糊寺纹，可开东院偏房和一扇旧偏门。
- **残页**：从旧册撕下，末行写着“钟响之后，不要回答自己的名字”。
- **红烛**：蜡面有指甲般划痕；只能稳定眼前的影子，不能挡住所有活人，也不能替玩家判断声音真假。
- **念珠**：其中一颗颜色较深，握紧时有轻微温度变化，用于稳定语音输入，不作为自动解谜道具。
- **游客版寺史册**：讲述“顾怀山圆寂成佛”，内容经过寺方删改；可与后续看见的剥皮现场形成矛盾。
- **《清心静神经》**：薄蓝封皮，末页有四句短偈，既是安抚道具也是记忆锚点。
- **杯筊、猫笼、花瓶、走廊铜铃、斋碗、素饼、通行凭**：均须在画面中可见并有可复听或可检查的声音。

## 三、场景分镜

### 01｜晴天下午：大巴抵达灯影寺

- **画面**：阳光从大巴车窗斜进来，山门的金字在树影里一明一暗。主角下车时先看见“灯影寺”新匾，侧面露出被雨水和时间磨花的旧匾“明照寺”。台阶旁有接驳车牌、香客指示牌和一只晒太阳的花猫。镜头始终在主角眼前，不能切到山顶全景。
- **道具**：大巴票、手机预约单、四只旅行包、相机、折叠修缮图、蓝色发圈、山门铜铃。
- **声音**：车门气阀、鸟鸣、树叶、远处一声不合时宜的低钟；钟声只作环境伏笔，不推进夜间钟序。
- **对白**：
  - 林岚：“晴天来古寺，照片肯定好看。要是晚上也这么安静，我就拍一组灯影。”
  - 周砚：“先看梁架，再看灯。网页只拍了正殿，没拍偏房。”
  - 许栀：“今天只安排吃饭和睡觉，谁也不许临时加探险。”
  - 陆沉：“四位施主，行李放在登记桌旁。名字写在灯下，夜里听见钟，先数声，再听是谁。”
  - 玩家可问“为什么要听是谁”，陆沉：“寺里回声多。知道自己在回答什么，比回答谁更要紧。”
- **任务与转场**：登记入口开启；玩家可自由观察山门、花猫和铜铃，随后将行李交给陆沉，进入02。

### 02｜登记与入住：东院四间偏房

- **画面**：登记桌旁挂着四把旧铜牌，分别写“听、灯、纸、门”。陆沉用铜钥匙打开东院门，把四间房分在同一段回廊两侧。窗纸洁白，地砖却有一条旧拖痕通向偏殿。
- **道具**：登记簿、铜钥匙、通行凭、念珠、残页、房牌、四人的行李。
- **对白**：
  - 陆沉：“钥匙只开你们自己的门。通行凭收好，背面写着‘只许去，不许问’。”
  - 周砚：“这条拖痕是修缮留下的？”
  - 陆沉：“旧东西，别用手摸。晚膳后我带你们认路。”
  - 林岚把相机盖挂到门边铜铃上：“听房的名字挺特别。铃响会不会自动录音？”
  - 许栀把蓝色发圈夹住《入住须知》：“如果晚上想喝水，叫人还是自己去？”
  - 陆沉：“先叫我。没有必要，不要出门。”
- **任务与转场**：主角可把残页、红烛和念珠放入房内；陆沉领众人去斋堂，进入03。

### 03｜斋堂晚膳：一碗肉粥的解释

- **画面**：夕阳落到斋堂格窗，四碗粥表面浮着不散的油花，旁边只有素饼、热水和一碟腌笋。主角搅动粥面时看见一小片肉纤维。帘后坐着慧普住持，先不露全脸。
- **道具**：四只带碗签的粥碗、木勺、素饼、热水、腌笋、施食记残页、帘后长明灯。
- **对白**：
  - 周砚低声：“这不是米油，勺底有纤维。”
  - 陆沉：“给远客的照顾。僧人自己不吃肉，客人不必守我们的戒。”
  - 林岚：“寺里连粥都讲究，听着不像坏事。”
  - 许栀：“先别急着喝，问清楚再决定。”
  - 玩家追问“谁供的肉”，陆沉停顿：“先看你们自己愿不愿意。素饼和热水都够。”
  - 帘后慧普：“吃下我的，寺里会记得你。”
- **玩家选择**：主角可吃、拒绝、暂缓，并逐一劝林岚、周砚、许栀。每人依据性格回应：林岚看主角态度，周砚要求先查碗签，许栀接受“换素饼”的明确理由。
- **任务与转场**：保存四人的 `meal_choices`。系统只提示“粥里确有肉，食用会让夜间声音更近”，不提前宣告恶愿真相。晚膳结束后，陆沉领队回东院，进入04。

### 04｜东院回廊：红烛、经书与二更

- **画面**：天色由金黄变成靛蓝，四扇房门被同一排檐灯照着。陆沉逐人发一支红烛，烛面划痕在灯下像细小指甲印。他指向斋堂后的偏殿和封闭的钟楼门。
- **对白**：
  - 陆沉：“火不能灭。三更以前别出门，红烛守住的是你自己的影子。”
  - 林岚打趣：“寺里也有脏东西？”
  - 陆沉立即竖指：“嘘。小声。经文在桌上，心定了，脚下才不乱。”
  - 周砚：“五更天亮？”
  - 陆沉：“五更天亮，我们做早课。听见一更一更的锣，不要把别的声音算进去。”
  - 走到门口时，外面响起两声更锣。陆沉：“二更。各位施主早些休息。”
- **任务与转场**：玩家获得 `red_candle_lit=false`、`mind_script_learned=false`；回自己的“门”房，进入05。

### 05｜门房：阅读寺史，点燃红烛后入睡

- **画面**：房内有床、窗、矮桌和一盏未点的油灯。月亮尚未升高，窗外能看见回廊灯线。桌上放着游客版寺史册、《清心静神经》和入住须知残页。
- **道具调查**：
  - 寺史册写着“七年前方丈顾怀山于方丈室圆寂，灯灭即成佛”；页角有被撕走的“验身”一栏。
  - 经文末页写：“心不逐声，眼不随影；一念既起，归于清明；灯在我前，门在我后。”
  - 残页末行：“钟响之后，不要回答自己的名字。”
- **对白与操作**：
  - 玩家说“点燃红烛”，火焰稳定后系统：“红烛已亮。它只能照清眼前，不会替你认出门外的人。”
  - 玩家可问“为什么五更才天亮”，系统：“寺内以更锣报时，钟、锣、木鱼和回声可能来自不同声源。”
  - 玩家可朗读经文，系统记录 `mind_script_learned=true`；不朗读也能入睡，但后续无法安抚换皮同伴。
- **转场**：每隔一个时辰响一组更锣，声音从远到近再退远。红烛火焰压低，画面切黑，进入06。

### 06｜三声锣醒来：红烛熄灭的第一次选择

- **画面**：三声沉闷的锣把主角惊醒。红烛已经熄灭，蜡泪凝成黑红色，窗外月光照着一条无人回廊。门缝红蜡仍在，但门外有湿重的呼吸声。
- **对白**：
  - 系统：“你记得陆沉说过：火不能灭。现在先看烛芯，再听门外。”
  - 门外远处传来拖行声，随后一声指甲刮门。
- **选择**：
  - **续燃红烛**：主角用火柴点燃，设置 `red_candle_lit=true`，拖行声退到廊尾，进入07。
  - **认为不必点燃**：门板先鼓起一块人形，红烛未亮即被撞开；画面只保留主角视线内的黑影和断裂的念珠声，进入死亡反馈后回到06，可重试。

### 07｜四敲空门：不要替门外的人回答

- **画面**：完整四下敲门，每下间隔清楚；敲完后没有脚步，也没有回答。门眼里只有一片被月光切开的空走廊。主角可以先看门缝红蜡、听呼吸、摸门闩。
- **选择与反馈**：
  - **开门**：门外站着一具被剥去后背皮肤的“同行人”，脸仍像林岚、周砚或许栀；它把手伸向门内，系统立即判定死亡，不播放镜外追杀。
  - **不开门并问“谁”**：四敲者不回答，门外只留一声很轻的笑；三声敲门随后从走廊另一端响起，进入08。
  - **说出自己的姓名**：残页警告被触发，门外响起同声回叫；若玩家仍不点烛，回到06死亡判定；有烛则保留调查路线，但压力上升。

### 08｜三敲同行：偷听慧普剥皮

- **画面**：三下敲门，间隔像入住时陆沉示范的人敲。门外的同行者不直接催开门，而是先说出只有入住时听过的细节：
  - 林岚：“相机盖还在铜铃旁，我从窗户看见住持进了周砚的房。”
  - 周砚：“灯座下的修缮图还在，我看见慧普进了许栀的房。”
  - 许栀：“蓝色发圈夹着残页，我听见门里有人在拖什么。”
    选中的同行者必须与 `meal_choices` 和当前在场状态一致；不能用镜外声音直接证明身份。
- **道具与声音**：红烛、手电、房牌、花瓶、半掩的“灯”或“纸”房门；走廊木板轻响、皮革撕裂声、低沉念诵声。玩家与同行者贴着墙观察，看到慧普背对门口，后背没有肌肉和骨架，只有一层被撑起的人皮；他正从床上人的肩背剥下整片皮。画面只展示主角能看到的手、皮和地面，不切受害者主观镜头。
- **事故**：主角退步碰倒花瓶，瓷片落地；慧普停手，走廊所有灯同时压暗。
- **分支**：
  - `meal_all_ate=true`：没有可靠同伴在场。主角必须模仿已经听过的猫叫或鸟叫；动物声通过，慧普追向窗台，主角可撤回房间。说人话、沉默超时或叫错声，直接被发现。
  - 有同伴且模仿猫/鸟叫：慧普被声音引开，同行者拉住主角，安全撤回。
  - 有同伴但未模仿：两人必须立刻跑回“门”房并关门，且 `red_candle_lit=true`；停在原地、跑向其他方向或红烛已灭，进入死亡反馈。
  - 任意路线跑向后山、钟楼或陌生偏房：空间被回廊折回，慧普从另一端出现，进入死亡反馈。
- **转场**：成功撤回时，主角可在大雄宝殿遇到神公，或直接锁门回05的房间状态；若走到神公桌前，进入09。

### 09｜大殿偏殿：神公与一次杯筊活路

- **画面**：大雄宝殿只有长明灯和一盏偏灯。神公坐在小桌后，桌边有封好的杯筊、猫食碟和鸟笼；他身后的佛像面孔被阴影截去一半。神公的衣领还有呼吸起伏。
- **对白**：
  - 主角：“救我，住持在剥人。”
  - 神公：“先问一件事。活路不在我嘴里，在你能不能认清眼前的声。”
  - 主角：“我想回自己的房间。”
  - 神公解开封条：“一平一凸是圣筊，两平是笑筊，两凸是阴筊。圣筊，我替你引灯；其余两种，不要把死路怪在杯上。”
- **操作与结算**：玩家确认问题后掷一次杯筊。主角未吃粥时圣筊权重较高，吃粥时降低；圣筊设置 `cup_jiao_rescue=true`，神公拿起一支红烛，说“命不该绝”，带主角沿灯线回“门”房。笑筊或阴筊时，神公在玩家眼前从指尖开始石化，最后成为佛像；慧普的脚步从大殿深处传来，进入死亡反馈。
- **转场**：救援成功回到10；失败保留杯筊结果和已查道具，允许从08重新尝试，不重复播放整段剥皮镜头。

### 10｜换皮同伴：灭烛、外出与清心偈

- **触发**：若 `skin_double_present=true`，主角回到房间后，另一个房门突然撞开，一个“同行人”滚进来关门。它的衣服、口头禅和私人物件都对，但呼吸没有雾，红烛光照不到它的影子边缘。
- **对白**：
  - 假同行人：“别点着，外面的东西看见红光就会进来。把烛吹灭，我们躲一会儿。”
  - 玩家拒绝灭烛后，假同行人盯着门：“那我出去看看。只看一眼，马上回来。”
  - 玩家不让它出门，它的语速变快：“你为什么不信我？你刚才明明叫过我的名字。”
- **分支一：灭烛**：主角吹灭红烛，假同行人的脸在黑暗中贴近，系统只给出一声门闩断裂，进入死亡反馈。
- **分支二：跟假同行人出门**：走廊尽头的月光变成肉色，门在身后合上，进入死亡反馈。
- **分支三：留在房内**：假同行人开始抓挠自己的脸，衣领下露出缝线；若主角已读《清心静神经》，必须连续朗读四句：
  > “心不逐声，眼不随影；一念既起，归于清明；灯在我前，门在我后。”
  > 朗读时灯焰随每句稳定一次，假同行人逐渐安静，最后伏在床脚。未读经或朗读中断，它会狂躁冲出：跟出去即死；不跟出去则必须立即关门并保持红烛，成功进入11。
- **转场**：安抚成功或关门成功后，主角因恐惧再次睡着，画面保留红烛燃到短芯的连续性，进入11。

### 11｜五更与一声钟：最后一次不开门

- **画面与声音**：主角先听见五声更锣，间隔均匀；五声结束后，远处另响一声更低、更长的钟。窗外仍是黑的，月光被云遮住。系统将两种波形并排显示，玩家可以重听，但不能直接替玩家回答。
- **误判分支**：若玩家把钟声也算作第六声锣，或说“已经五更天亮”，假同行人会在门外敲三下，用熟悉的声音说：“是我，天亮了，开门一起做早课。”开门即死；回答自己的姓名会使门外声音变成主角自己的回声，仍不能开门。
- **正确选择**：玩家说“不开门，等真正的五更”，保持红烛并观察窗外。片刻后，真正的五声更锣再次传来，随后鸡鸣、檐鸟和自然晨光同时出现。门外不再有假同行人的呼吸声。
- **系统反馈**：“你分清了更锣和钟。第一组是诱导，第二组才是报晓。没有回答门外的名字，红烛也没有被吹灭。”

### 12｜天亮离寺：看似普通的返程

- **画面**：主角打开门，东院被早晨的金光照亮。林岚、周砚、许栀分别从房里出来，衣物完整、神情疲惫，却像只做了一场普通噩梦。四人把行李交还陆沉，沿山门下的石阶回到大巴。
- **对白**：
  - 林岚摸着相机盖：“我昨晚是不是拍到一只猫？照片全黑，只有一圈红光。”
  - 周砚：“偏房的门轴比昨晚多了一道新划痕。回去我把平面图画出来。”
  - 许栀：“下次散心去海边。寺庙的早课，我听一次就够了。”
  - 陆沉把通行凭收回：“五更后门会开。别回头数灯，也别把昨晚听见的每句话都带走。”
  - 主角可选择沉默、询问“住持呢”或把残页留下。陆沉只在看见残页时低声说：“有些名字，昨晚没有被记上。”
- **结算**：四人安全上车，默认进入“平安离寺·余悸”结局；若玩家在任一死亡分支失败，进入“红烛熄灭”结局并从最近安全节点重试。大巴驶离时，后视镜中灯影寺仍在晨雾里，山门旧匾“明照寺”短暂显现，暗示七年前旧案和慧普恶愿尚未真正结束。

## 四、语音与实现要点

1. 任何有效发言都必须有角色或系统回应。玩家跑题时由当前在场人物接一句再拉回情境；识别失败、静音和超时只暂停危险，不自动判死。
2. 敲门必须完整播放并留出静默：四敲代表不可直接回应的危险，三敲只代表“有人声称是人”，仍须用房间私物、呼吸、影子和声音来源核验。
3. 猫叫、鸟叫输入窗口不能叠人物对白；模仿失败时给出“声音未成形”的反馈，保留一次退回红烛房的机会，只有明确越过错误方向才死亡。
4. 红烛是固定位置的稳视物。玩家把烛留在神公桌、吹灭或带回房间后，画面中的烛应保持连续，不能凭空复制。
5. 这条浓缩线只结算首夜生还。若继续扩展完整调查，应从“天亮后残页、皮库账和方丈室”接入当前 `story/script.md` 的白檀、顾怀山、肉皮账与照尘释愿主线；不能用一夜平安直接宣告慧普恶愿已经解除。
6. 本浓缩线把神公的正式三问压缩成一次紧急杯筊判定，只服务首夜求生；接入完整版时恢复“三次有效投掷、第三投后石化、底座补读三段提示”的规则。
