# 《众誓堂·灯影寺：无声钟》

单人第一视角密室逃脱、古典本格推理与语音互动的完整关卡稿。

这是一款由一名真人玩家扮演主角“你”的密室逃脱游戏。你与林岚、周砚、许栀三位同行 NPC 到灯影寺游玩，原本只想看夜景、吃素斋、住一晚寺院偏房，却在入住后被卷入七年前的方丈室密室死亡案。玩家始终只控制自己的视线、移动、发声、调查与选择；所有同行、僧人和证人均由系统演出。寺院里的喇叭、铜管、木鱼和回音壁能录下你的声音，也能伪造你听见的声音。你的目标是恢复自己的记忆、查明旧案，并决定是否救出三位同伴、是否把证据带到寺外公开。

设计目标：

- 全程坚持主角第一视角：画面只呈现你所在空间可见的事物，声音只呈现你能听到的声源；不切换 NPC 操控、不用全知分屏交代幕后行为。
- 让玩家先相信一个声音，再亲手找出它的矛盾。
- 每个谜题至少提供两条独立线索；玩家可以推理出答案，不必依赖猜关键词。
- 语音是操作方式，也是剧情中的证据。说错会增加压力，但不会永久锁死关卡。
- 所有失败都给出角色或系统反馈；跑题、沉默、识别失败不会被当成错误行动。
- 结局由玩家的推理、路线、救援和证据公开选择共同决定；NPC 的惊慌、跟念或失联不会自动算成玩家的决定。
- NPC 可按“停下、跟我走、在灯下等、把物证给我看、完整复述”等指令协助，但不会替主角得出谜底，也不要求另一位真人补齐操作。

民俗惊悚主线：

- 灯影寺的“成佛”传说不是装饰，而是七年前投票控制术的源头。
- 半夜离开偏房时，玩家会遇到披着人皮袈裟的和尚，也会遇到一个“看起来完全正常”的同伴。玩家必须用记忆、呼吸、影子和声音核对身份。
- 真假同伴机制只制造猜疑，不强迫玩家靠随机猜测推进；每次判断都有至少两条可验证线索。
- 钟楼是另一条生路。它不能用铜印直接打开，必须让“法华”完成一次反向成佛，逼慧普放行。
- 上香、四大天王、偏殿掷杯筊、三敲四敲和生死幡构成一条可追踪的民俗调查链；仪式表象与证据结算分开，神明的答复不能代替物证。
- 午夜大殿上方会响起像巨物爬行的轰隆声；偷听者会意外碰倒花瓶，必须借入住时听过的猫叫或鸟鸣掩护自己。两场惊吓都提前埋线、允许复核，失败回到安全调查点。

## 一、玩家知道的故事

灯影寺原名“明照寺”。七年前，方丈顾怀山在方丈室内死亡。房门从内反锁，窗户钉死，火盆没有被碰过，室内只有一盏即将燃尽的长明灯。寺里当晚有四名见证人：守夜人陆沉、司灯人白檀、记录官纪归年，以及当时的副导师顾惟真。

顾怀山死前留下了一句被反复传唱的话：

> “第三声钟响以后，不要回答自己的名字。”

寺里随后举行了一次“净化投票”。众人投票认定顾怀山的弟子沈墨是“污染源”，沈墨失踪，所有相关记录被封存。寺方档案声称顾惟真随后接替方丈，创立“众誓堂”，把当晚的投票、钟声和长明灯改成仪式；这是你最初读到的官方叙述，是否出自本人仍待查证。

七年后，灯影寺以“古寺夜游、灯影观景和禅房体验”为名重新接待游客。你与三位朋友周末自驾前来：林岚喜欢摄影，周砚研究古建筑，许栀提议庆祝你的近况，也想借旅行散心。寺庙官网写着“可体验长明灯、木鱼和夜间钟声”，因此你们预订了东院的四间偏房。三位朋友都是有独立情绪和处境的 NPC，玩家不能切入他们的视角；他们的说法只有在你面前说出、通过铜管传来，或由你找到录音后才进入调查笔记。

你们到寺时已入夜，接待钟显示21:35。山路被一场突如其来的暴雨冲坏，负责接待的守夜人陆沉告诉他们，今晚只能留宿寺内，等天亮后再下山。陆沉把四人分别安排在大雄宝殿东侧的偏房，并提醒：

> “夜里听见钟声，不要在房里回答自己的名字。寺里的回声会把人的话送到不该去的地方。”

四人先完成入住、吃过简餐；22:05参加寺庙安排的“灯影夜游”。导览没有出现，只有一盏长明灯、一段关于七年前方丈死亡的旧介绍，以及一封夹在客房《入住须知》里的旧信。信上没有署名，只写着：

> “如果你认为七年前那不是自杀，请在子时前来灯影寺。带上自己的声音。不要相信回放。”

22:05夜游开始，你随三位同伴穿过寺门前的香庭。檐下的旧铜炉积着湿香灰，三炷刚点燃的线香在雨风里向西弯，空气里有柏木、旧灯油和潮湿石阶的气味；远处一只花猫钻过供桌，檐角有夜鸟短鸣。大雄宝殿前厅保留原天王殿的四龛格局，东持国持琵琶、南增长持宝剑、西广目持龙蛇与宝珠、北多闻持宝伞，四尊完整造像各据寺院真实方位。四人以为可以循着“风调雨顺”的旧香牌完成普通祈福，却没有发现香牌已被人错换。接待的陆沉不劝人许愿，只说：“香可以供，名字别跟着喇叭报。寺里有些东西，只循人语，不认猫鸟。”

夜游末段，陆沉指向前厅东侧的小偏殿：“那位守殿和尚，山下人俗称神公。他守的是旧杯筊桌，不是佛名。想问路，先听他把规矩说完。”偏殿里的人不抬头，只用拇指摩挲一对红木杯筊：“一句一问，落定才算。三问之后，不再开口。”游客此时可以先记下规则，午夜再来完成三问；即便此时完成全部三投，第三投后的石像变化仍会发生，但夜间声源和生死幡线索只登记为待核实。

你们以为这是寺庙准备的沉浸式解谜活动，把旧信当成夜游的一部分。入住时，你亲自陪同伴走到各自门口：林岚住“听”房，周砚住“灯”房，许栀住“纸”房，你住“门”房。你看见林岚把镜头盖放在铜铃旁、周砚把修缮图折在灯座下、许栀用蓝色发圈夹住《入住须知》残页；他们各自随口说出的房间细节也由你亲耳听见，记录在个人笔记中。后面的身份核验只使用你已见、已听、可再查的信息。

夜游后回到东院廊桌，你喝过安神茶，先听见杯沿轻碰，随后画面失焦、黑下去；黑场里断续有铜铃和一句模糊的“让他再睡一会儿”。你并未亲眼看见谁移动你，也不知道同伴去了哪里。饮茶是序章中已经发生的亲身记忆，可以跳过回忆；昏迷段不开放玩家行动，不展示 NPC 集体投票的镜外画面，不把这些残声直接当作已确认事实。

你醒来时独自在“门”房，手表、手机、枕头和门缝红蜡彼此矛盾。门外先后响起三敲与四敲，喇叭声从走廊传来：“缺席者已经选择沉默。”你可以先搜查自身醒痕、核验敲门者，再自己决定走向大殿；不需要另一名玩家来找到或叫醒你。之后通过同伴当面口供、可复听录音和搬动痕迹，才逐步还原：你昏睡期间，三位同伴被引到大殿，广播试图替你记下一票。

当你亲自走到大殿，第一轮“净化表态”仍未结束。林岚反对把缺席算同意，周砚想先找到出路，许栀害怕再不回答就会被关在寺里；三种意见通过你眼前的 NPC 对话制造压力。顾惟真的喇叭要求你亲口作最后确认：“少一个人，剩下的人才能拿到出口钥匙。”你只决定自己的表态，也可打断广播、要求找原始记录或撤销代签。NPC 不替你投票，他们说过的话也不能被系统当成真人操作。

广播不因你拒绝而停止，但你的拒绝会留下可追查的反证。你可以对许栀说“先别重复它的话”，请林岚出示原照片，请周砚完整描述灯芯；如果你暂时独自调查，他们会在你指定的灯下等候。偏房由住宿空间变成你可以亲自回访的证据区，不再依赖四名真人各握一条秘密。

## 一之二、错钟夜：失去的四十四分钟

本段把“被迷晕”写成主角的主观叙事和可验证的时间谜题。游戏用第一视角失焦、黑屏、短声片与调查道具表现失去记忆，不涉及真实药物。昏迷始终发生在唯一主角身上，三位同行 NPC 的去向只能在醒来后查证。下表属于制作内部真相，不能通过过场镜头直接给玩家看。

### 当前夜的真实顺序

```text
21:35  四名游客抵达灯影寺，先办理偏房入住，再吃简餐
22:05  参加灯影夜游，经香庭、四天王前厅、偏殿杯筊桌，读到无署名旧信
22:18  主角在东院廊下喝过故事中的安神茶，失去记忆；林岚只见主角伏桌，未见幕后移动
22:24  偏房铜铃响三次；三名同行 NPC 按广播前往大殿；白檀启动搬运、假钟和回放设备
22:31  白檀把主角移回偏房，拨快大殿钟，冻结手机界面，剪掉一段广播前的静音
22:53  播放七年前旧案的第一声钟与顾怀山录音
23:02  主角醒来，偏房假钟显示 00:02，手机录音显示 23:00 但开头缺失
23:12  大殿第一轮“净化表态”进入主角确认段；三位同行 NPC 的先前发言可查，主角昏迷的沉默始终不计票
23:18  播放旧案第二声钟；假钟诱导主角以为当前已经过了子时
23:24  播放旧案第三声钟；其显示标签为00:18，不能与主角真实醒时混淆
23:26  后山水泵启动并运行30秒（每30分钟一轮），罗汉堂水钟滴满半格，提供第一个不受喇叭控制的真实锚点；大殿上方同步出现一次巨物爬行般的滚响
23:35  方丈室证据开放，玩家开始把当前夜与七年前旧案分栏校正；偷听白檀与陆沉时触发花瓶脱险支线
```

主角实际从22:18到23:02约有44分钟缺口，录音被剪掉的14分钟只是其中一段。你的主观顺序会变成“22:46 醒来—00:02 看见假钟—00:18 听见第三声—天快亮了”。真实顺序却是“安神茶—移动—旧案录音—醒来—集合”。白檀把七年前的 22:46—23:10 剪进当前夜，制造“刚过子时”的错觉。

### 主角醒来时看见的矛盾

主角醒来后，系统先不报时间，只呈现三件你可亲手观察、拍照和复听的物品：

1. 手表停在 22:46，但电池仍有电，表冠外有一圈硬化红蜡；
2. 手机录音标注23:00，原本开头14分钟被删除并以静音/重复雨声填补；
3. 安神茶只剩半杯，杯底有蜂蜜和偏房专用红蜡，枕头上有被搬动后的压痕。安神成分只属于故事中的茶，不来自正常供香；拒绝上香不改变环境调查，也不会被强制改写成吸入香烟昏迷。

三名 NPC 提供的是待验证观察：林岚可出示铜铃照片及原录音，周砚可拿出灯座下的修缮图并带你看剪短灯芯，许栀可指出两段广播中的同一声雷。你必须自己查看相应物件、复听录音并提出结论。任何一条口供都不能独自证明具体分钟；至少两件物证加一段声音或环境锚点，才能改写时间线。

### 时间假设板

玩家可以用语音说“记录当前显示时间”“冻结所有钟表”“按事件排序，不报分钟”“把旧案和今晚分开”。系统把看到的时间当作待验证线索，而不是正确答案：

| 来源           | 玩家最初看见的值     | 可验证的偏差                                                                       | 真实用途                 |
| -------------- | -------------------- | ---------------------------------------------------------------------------------- | ------------------------ |
| 主角手表       | 22:46                | 表针被红蜡卡住，电池仍在走                                                         | 证明停表发生在人被移动后 |
| 偏房假钟       | 00:02                | 铜铃与钟芯不同步                                                                   | 证明偏房钟被替换或拨快   |
| 手机录音界面   | 23:00                | 开头 14 分钟被剪掉                                                                 | 证明录音不是连续现场记录 |
| 大雄宝殿机械钟 | 00:42                | 齿轮拨快，外壳有新划痕                                                             | 证明白檀能改动公共时间   |
| 罗汉堂水钟     | 未翻转半格           | 受后山水泵控制，不能被喇叭改写                                                     | 提供当前夜的顺序锚点     |
| 后山水泵声     | 玩家以为是第二天清晨 | 与30分钟启动周期、每次运行30秒一致；一次泵声只能锚定事件顺序，不能独自推算整夜时长 | 确认“假天亮”仍在夜里     |

### 必须得出的四个结论

1. 主角在第一段旧案钟声之前已经昏睡，醒来时间被伪造；
2. 三声钟沿用同一段旧案录音，当前夜只发生过一组三响的偏房铜铃，殿内三段旧钟声均非现场敲钟；
3. 不同钟表各有偏差，不能用多数钟表投票决定时间；
4. 七年前旧案的时间被剪进当前夜，白檀利用时间缺口制造了“仪式正在自然进行”的假象。

发现任意两项矛盾即可开启“时间校准”，不把口述完整结论当前置。四点是校准最终结论：主角完成事件排列设 `order_rebuilt`，使第二轮伪时序作废；四点全对并保留醒痕，才可获得时间强化结局。

### 醒来节点对白

- 玩家：“我刚才睡了多久？”
- 系统：“我只能给出你的主观时间。钟表没有证词。先问他们最后亲眼看见了什么，再找能核对的物件。”
- 玩家：“检查杯子、枕头和手表。”
- 系统：“杯底有双层蜡膜；枕头被拖动过；表停在 22:46，电池却仍然发热。它们证明你被移动过，还不能单独证明是谁动的。”
- 玩家：“把三声钟放一起。”
- 系统：“三段声音都有同一只狗叫、同一滴雨和同一声门轴响。白檀插话：‘你们只是听见了同一座寺。’若玩家回答‘这是同一段录音’，记录声音证据。”
- 玩家：“谁送的茶？”
- 陆沉：“我看见走廊钟写着22:40才端进去，以为只是安神茶。那只钟后来被证实拨快了；对照换班牌，实际是今晚22:18，和七年前搬钟油的22:40不是同一件事。”
- 白檀被问到“你是22:46还是23:03添油”时沉默两秒，只重复已有记录。这证明她在回避具体时间，或此声道用了预录；不能据此断言当前实时操控者白檀没有现场记忆。
- 玩家：“录音里说我同意了，可我那时还没醒。”
- 系统：“这是一项待核对的指控。把枕印、杯沿和录音开头放在一起，再决定是否要求撤销代签。”
- 玩家：“我的沉默不是同意，恢复我的原始证词。”
- 陆沉：“你现在亲口说的，才是你这一票。之前那一格，我会留下被改写的痕迹。”
- 玩家：“现在天亮了吗？”
- 系统播放预录的班车报站。若玩家说“关掉月影投影，听原始雨声”，会发现仍是夜里并开启“假天亮”支线。

### 时间诡计的收束台词

当玩家完成时间校准，系统不直接公布正确分钟，只让已核录音提示：

> “你们不是错过了一个小时，而是被同一小时播放了三遍。”

若玩家仍坚持“现在已经天亮”，真实的后山水泵启动，水钟只翻过半格。若玩家说“按事件排序，不报分钟”，调查板列出你已取得的物证、亲历和口供，三位 NPC 只补充各自确实见到的动作；事件卡仍由你排列，系统不代填结论。

### 时间状态旗标

- `gap_open`：主角确认自己有一段记忆缺口；
- `clocks_conflict`：发现至少两种钟表或录音时间互相矛盾；
- `anchor_found`：找到水钟、水泵或其他不受广播控制的环境锚点；
- `replay_proven`：确认三声钟拥有相同背景声，是同一段回放；
- `order_rebuilt`：按事件先后而非显示分钟完成时间线；
- `witness_restored`：主角亲自复核醒痕、确认昏迷沉默不能作同意，并恢复本人证词资格；
- `false_dawn`：识破月影投影和预录班车报站；
- `white_sandal_witness`：完成白檀灯芯账，让她交出未剪辑录音。

只有 `order_rebuilt` 才能用事件顺序直接使第二轮假表态作废；未完成时仍可拒绝授权并继续调查。`witness_restored` 与保存、公开醒痕证据共同构成主角的有效证词，不要求另一位真人为主角背书。

## 二、隐藏真相（制作与游戏系统）

七年前的死亡不是自杀，也不是鬼怪作祟。

1. 顾怀山发现顾惟真正在利用诵经喇叭和投票控制会众，准备在第三声钟后公开账册。
2. 顾惟真在七年前 22:46 使顾怀山失去意识，取走钥匙，并在第一声钟播放前将其杀害；之后的声音都是预录，不是存活证明。具体施害过程不作为玩家操作。
3. 白檀按顾惟真的命令提前剪短长明灯灯芯，制造“灯先灭、人在后死”的假时间线。
4. 顾惟真从佛龛后方的检修夹层离开方丈室，再用涂蜡的铜丝从门外拉回门闩。铜丝被藏进门槛的裂缝，蜡屑落在红色经幡上。
5. 顾惟真预先录下顾怀山的声音，在 23:00、23:03、23:06 播放三次钟后遗言。所有人听见“第三声钟”时，顾怀山已经死亡。
6. 纪归年把投票记录改成“全员同意”，陆沉因为家人被扣留而保持沉默。
7. 沈墨没有杀人。他在发现录音和铜丝后，试图把证据藏进罗汉堂封墙，随后被顾惟真以“污染”罪名驱逐。
8. 投票结束后，顾惟真回到检修夹层销毁铜丝和原始账册。夹层的回门机关被白檀提前卡住，顾惟真被困死在墙后；白檀把他的尸体封进废弃的灯油井，并保留了他的录音。
9. 顾惟真死后，白檀把一套“披人皮袈裟”藏进钟楼。袈裟由薄牛皮、旧僧衣和灯油胶制成，能在远处伪装成僧人；这一具可检验的假人利用雨幕、逆光和玩家的恐惧移动；该结论只解释带蜡线的样本，不能自动否定四敲、动物声回避、石化与生死幡中尚未验证的现象。
10. 白檀把慧普的传说改写成“吃下外来者的肉就能成佛”，用来解释失踪游客和鼓励会众服从。真正的老记录只写“鹰食我肉，我取鹰皮”，意思是舍弃执念、剥下伪装，而不是吃人。
11. 香庭、偏殿与生死幡曾是寺院旧游线。白檀错换四天王的方向香牌，用香烟气流掩饰检修风道；又利用杯筊桌中的三段录音、暗龛与石像轮换底台，试图让游客相信“问神三次会把人问成石头”。轮换底台、帘影和停电可以解释一部分换位过程，但不足以证实玩家眼前的人是否被替换；第三投后“人变成同姿石像”是玩家必见的事实，石像掌心没有对应来源的新香灰仍留作未解释的余味。
12. 夜间三下敲门是守夜人约定的真人联络信号；四下警示玩家按“鬼敲门”处理。其中一组四敲可查到门后撞针和披皮巡游，另一组会在撞针断开后重现，不允许用一个机关归因所有四敲。三下只能证明使用真人联络节奏，仍必须核对私密入住细节与脚步；四下并不自动证明世上有鬼。
13. 大殿屋顶可被复现的部分滚响由旧运灯轨、覆皮滚架和后山水泵共振造成。声音从山门上方滚到主殿北檐、越过南脊，又沿空心梁绕到耳后，听来像有巨物从整座寺庙上方爬过。可见的轨油、同步振动和水钟锚点能拆出机械部分；末尾多出的一步保留为无法确认的民俗尾声，不承担谜底。
14. 白檀把生死幡的“生、死”顺序和证人名签调换，用它把静默剪成“愿意留下”。方丈室外的花瓶靠近偷听位，跌落会引来只追逐人声的披皮巡游；没有证据证明花瓶是白檀故意布置，不能把意外当作其自白。猫叫或夜鸟声能使巡游转向香庭；玩家必须先发现动物声与巡游的对应反应，而非临时猜中一声叫。

现在的“导师声音”仍在播放，但顾惟真本人已经死于七年前当夜投票后的检修夹层事故。“接替方丈、创立众誓堂”是白檀借其录音发布的继任与新制度公告，不能作为他活过那一夜的证明。真正操控这一夜的人是白檀。她是当年唯一掌握灯阵、录音机和检修夹层的人，也继承了顾惟真的手册；她没有亲手杀死顾怀山，却故意让杀人者死在墙后，再用他的声音继续统治。她想让玩家在恐惧中选出一位新的“导师”，让七年前的循环继续。

白檀不是单纯的反派。她曾试图公开真相，却发现所有人都更愿意相信“被剪辑过的多数”。她因此得出错误结论：只要让人先服从，再给他们一个出口，他们就会主动替操控者守门。玩家若能用证据拆穿她，她会在终局留下最后一段未剪辑录音。

### 慧普与法华｜被篡改的成佛传说

很多年前，灯影寺有一位法号慧普的法师。他十岁出家，一生钻研经文，却到临终仍未参悟大道。晚年的慧普把“没有结成舍利”视为失败，逐渐疯癫，开始把一切痛苦解释成“离佛位只差最后一步”。

慧普曾命弟子法华把自己割下的肉熬成粥，喂给寺中僧人，声称这是“割肉喂鹰”的最后一关。法华的师父只完成了救护和安葬，没有让僧人食用人肉；但当夜长明灯恰好稳定，寺中众人便把慧普的死亡误传成“成佛”。法华在旧经页边写下了真正的警告：

> “师父说得果然没错，你从来没有成佛。一切都是你的执念。成佛二字，害了灯影寺所有人。”

后来顾惟真和白檀把这段警告改成仪式歌词，并补上四句骇人的伪经：

> 行祂所行，得祂所获。  
> 摘下心脏，熬成汤粥。  
> 剥下人皮，制成袈裟。  
> 鹰食我肉，我取鹰皮。  
> 上参诸佛，下备香火。

这五句是反派宣传词，不是玩家必须相信的事实。玩家在钟楼会找到法华的原始纸条，证明“取鹰皮”指的是剥下伪装，“心脏”指的是执念，并没有任何食人仪式。这样既保留民俗恐怖，也让本格推理能够揭穿传说的篡改。

### “第四夜”旧档案｜宁秋水一行人的逃生记录

在钟楼的旧木箱里，玩家会找到一份被撕去封面的旅行记录。记录者是几年前来灯影寺游玩的宁秋水，同行者有刘承峰、沈微微、单宏，以及后来赶来寻找沈微微的段曾天。五人原本也只是住在偏房的游客，却在第四夜听见法华的纸条召唤。

档案记载：宁秋水、刘承峰、沈微微三人带着点燃的红烛前往钟楼；单宏不相信纸条，留在大殿；段曾天在半路识破一名披人皮和尚后，帮助沈微微越过菜善等伪装僧人的阻拦。钟楼上，三人看见只剩一张人皮披在骨架上的法华。法华告诉他们，寺庙的出口不是打败慧普，而是让法华“以另一种方式成佛”，从而迫使慧普放行。

记录里的最后一页只有一段对话：

> “师父说的果然没错，你从来都没有成佛。”  
> “一切都是你的执念。”  
> “成佛二字，害了灯影寺所有人。”

三人随后点燃钟楼的血门，门外出现一具被称作“血尸”的披皮僧人。旧档案说，法华以成佛威胁慧普，直到血尸快要走入大殿，慧普才放三人离开。玩家无法确认这究竟是鬼魂、机关、录音和披皮道具共同造成的幻觉，还是寺庙真的留下了某种意识；但档案中记录的路线、红烛和钟声间隔，都能在当前夜游中被复核。

宁秋水的记录不是当前关卡的直接答案，而是一条备用生路：如果玩家在方丈室推理失败，仍可通过“红烛—钟楼—法华纸条”路线获得逃生机会；如果玩家集齐当前案件证据，再对照旧档案，则能发现白檀正故意复刻宁秋水一行人的恐惧，把“法华放行”剪成“慧普吃人”。

### 怪异现象的双层解释

灯影寺允许两种解释同时成立一段时间。第一层是可调查的现实解释：披人皮和尚来自薄皮袈裟、雨幕、铜管变声和隐藏演员；血尸来自骨架、红蜡机关、投影和白檀预先剪好的录音；“慧普放行”来自钟楼铁闩与远端操控。第二层是无法完全证伪的民俗解释：法华的执念可能留在皮下铜管，慧普可能仍在长明灯熄灭时听见每一轮游客的声音。

玩家不需要在结局前选定哪一层是真的。只要能指出“哪些部分被人操控、哪些部分无法解释”，就算完成了调查。这样既保留金田一式的机关还原，也保留寺庙传说在最后一声钟后的寒意。

## 三、人物与可验证的口供

### 0. 唯一主角与三位同行 NPC

**主角“你”**：唯一由真人控制的人物，住“门”房。开场不预设你相信神鬼，也不替你选择是否上香。你负责观察、发问、排列事件、判断身份、选择路线、救援与最终宣言；镜头始终是你的眼睛，拿物和机关操作通过第一视角手部或近景反馈。你不知道的事不能因 NPC 镜外做过就自动成为证据。

**林岚｜摄影者，住“听”房**：嘴硬、敏锐，遇到危险会本能举相机，以为拍到的就一定是真的。她最想带大家完整回去，也怕自己的延时照片害人。她先说“铜铃响时你还在廊下”，照片元数据却被假手机界面误导；玩家可要求查看原始连拍，凭相邻帧中的雨滴和未动过的镜头盖核验。她会依指令在柱下等、照出侧影、出示照片和报自己最后看见的动作，不会替你宣布谁是鬼。用两项身份线索确认她后，她愿意交出相机；失联时相机留在你目击的等候点，主角仍可用自持红烛与地面脚印核验。救援通过三敲、镜头盖位置与侧影确认后由你引回灯下，她不因一句‘相信我’自动恢复信任。

**周砚｜古建爱好者，住“灯”房**：克制、讲道理，最初把异象一概归为旧建筑机关，因此低估屋顶最后一声擦响。他的目标是找到检修出口，矛盾在于“我没离开过灯下”与修缮图上的新湿指痕；核查后可知他只走到梁柱边找漏雨，不能由此直接认定杀人。他可按指令指图、扶灯、在安全线等、逐段跟随，但不能独自替你停泵或开密室。你展示轨油与水泵同步两项物证后，他承认有些声响无法解释。即使他被假声引离，图纸已经由你拍下，停泵、铜丝和压力板仍可独立解开；你循干湿脚印到检修窗，通过未公开折图方式与真人影子核验后救回他。

**许栀｜旅行提议者，住“纸”房**：善于照顾气氛，因想把庆祝旅行办好而自责，害怕大家争吵时会想先答应广播。她最想尽快离寺，却也不愿抛下任何人。她说“我没有同意留下谁”，回放里却出现她的‘我同意’；玩家可用蓝色发圈夹着的原始残页和前后句，证明她原话是‘我同意先找人’。她可收好你交付的副本、复述原句、留灯等候并当面声明去留；她的恐慌不直接增加玩家压力。主角说明证据与路线后，她会照明确指令行动。若被假天亮诱导，脚步会在你可见的转角离开，留下蓝发圈标记；你先熄投影、再以相处细节和原声把她带回，不需要切换她的操控。

**NPC 指令边界**：‘等在这里’明确回复等候地点，‘跟我走’明确回复跟随到下一安全节点，‘一个一个过来’按你指定顺序行动，‘不要回答喇叭’使其停止跟念。含糊指令先澄清。NPC 不消耗真人回合，不因自己的台词让你被判错；玩家未授权同时冲刺时，NPC 误迈只触发可见预警并退回安全线。任何 NPC 失联都会留下你能亲查的原因、最后位置与补救入口；普通逃生不以三人齐聚为前置。红烛、录音机、地图副本与镜片均可由主角携带，关键谜题不依赖 NPC 独占技能。

### 1. 顾惟真｜导师（只以录音出现）

- 对外形象：慈悲、沉稳、擅长用短句制造共识。
- 常用语：“灯不灭，人升维。”“多数已经替你做了选择。”
- 公开口供：22:30 后一直在大雄宝殿主持诵经，没有进入方丈室。
- 破绽：录音中每次“第三声钟”后的混响完全相同；现场铜钟的余音长度却会随门的开合变化。
- 剧情作用：玩家最初相信的权威，也是第一个需要被证伪的“证人”。

### 2. 陆沉｜守夜人

- 对外形象：掌钥匙、掌门禁，像是最容易杀人的人。
- 口供：22:50 在走廊听见方丈室内有人说“不要回答名字”；23:06 才发现门已反锁。
- 真相：他在 22:40 被顾惟真叫去搬钟油，未看见方丈室；他记得门槛有新鲜蜡屑，但不敢说。
- 语音反应：被直接指认时会沉默；玩家说“你是在保护谁”会承认“我保护的是还活着的人”。
- 红鲱鱼：拥有钥匙，却没有进入夹层的工具。

### 3. 白檀｜司灯人（前段广播，灯芯账当面质询）

- 对外形象：前段没有公开肖像，只在灯影和变声喇叭里出现；你在灯芯账质询时首次当面见到她，终局才听到完整动机。
- 口供：她说自己 23:00 在后山添油，没见过方丈。
- 真相：她知道灯芯被剪短、录音机被启动，也知道铜管的回声会延迟。
- 语音反应：玩家说出“这是预录的”“灯芯被剪过”“铜丝在门外”中的任意两项，她会停止篡改回放三十秒。
- 动机：她既想掩盖自己卡死夹层、放任顾惟真死亡的事实，也想用玩家复刻七年前的投票，证明“没人能抵抗多数”。

### 4. 纪归年｜记录官

- 对外形象：负责写名册，强调“记录就是事实”。
- 口供：七年前的投票记录显示四人一致指认沈墨。
- 真相：原始记录上只有一票指认沈墨，另三票是同一支笔、同一时间补写的。
- 可验证线索：纸张边缘的灯油污迹只有一张，说明记录不是同时完成。
- 语音反应：玩家说“把原始记录和回放放在一起”会给出“第三页背面”的位置。

### 5. 顾怀山｜死者（遗留录音）

- 最后完整录音：“钟声可以伪造，回声不会替你投票。”
- 关键提示：真正的遗言不会在三个房间里拥有完全相同的回声。
- 情感作用：玩家不是替死者复仇，而是替一个曾经拒绝投票的人恢复发言权。

### 6. 沈墨｜被投票者（墙中遗言）

- 留在铜管里的声音：“他们把我叫作污染源，是因为我问了第二个问题。”
- 他没有提供答案，只提供验证方法：比较钟声、灯芯和门槛。
- 若玩家在终局说出“沈墨没有杀人”，会触发隐藏结局条件之一。

### 7. 法华｜钟楼的剥皮僧（残留意识）

- 法华是慧普晚年的弟子，也是唯一留下反驳“成佛方法”的人。
- 玩家在钟楼看见的“法华”只剩一张贴在骨架上的人皮和一盏未点燃的红烛；说话声从皮下的铜管传出，是法华生前留下的录音。
- 他不会要求玩家相信自己，只会给出验证方法：“看衣襟内侧。真的僧袍有三道叠缝，披人皮的和尚只有一条热蜡线。”
- 若玩家带着红烛来到钟楼，并说“你没有成佛，是执念留下了你”，法华会播放完整纸条，启动血门的逃生机关。

### 8. 披人皮的和尚｜移动伪装

- 不是不死怪物，而是白檀制作的薄皮袈裟、旧僧衣和铜管变声器。
- 远看像没有脸的和尚，近看会露出错误：手指关节没有佛珠压痕、脚步没有僧鞋木底声、影子比身体多出一截。
- 它会模仿主角与NPC刚才说过的话，制造怀疑；它不能回答主角亲历但未被公共喇叭录入的入住细节。
- 玩家若把它误认为同伴并跟随，路线会被引向假出口；若识破，则从它身上取得钟楼钥匙和一小片人皮袈裟。

### 9. 菜善｜守门僧群的名字

- “菜善”不是一名可被单独信任的 NPC，而是旧档案里对守在后山路口的披皮僧群的统称。
- 真正的菜善只用三下木鱼表示“有人经过”，不主动喊游客姓名，也不要求游客回答自己的身份。
- 白檀会让假菜善先喊出玩家姓名，再把“回答姓名”剪成服从证据。玩家识破这一点后，可以把菜善的三下木鱼节奏作为后山路线的安全信号。

### 10. 神公｜偏殿守筊和尚

- “神公”是山下人对守殿和尚的俗称，不是佛教神祇名称。他自称守的是“问题和落定的声音”，不接受别人替同伴发问。
- 杯筊形制固定：按落定后朝上的一面读筊：一平一凸为圣筊、两平为笑筊、两凸为阴筊。它们是故事里的仪式读法，不被系统当作刑侦事实或道德裁判。
- 三次有效投掷依次揭示门槛、声源、生死幡。第一投圣筊：“香灰落在炉里，红蜡落在门外。你问路，先看门槛。”第二投笑筊：“你笑他像鬼，鬼也笑你认声音作人。头顶会走的，不一定有脚。”第三投阴筊：“生死不在杯中，在谁替谁写名。第三问毕，莫再问我是谁。”
- 同局 `cup_cast_count` 从0累加到3，跨场景离开、回访或B/C机关复盘不清零；只有开启新一局才重置。第三次有效投掷一落定即开始石化：他的袖口停止晃动、指尖泛灰，最后答语以口中同期残声和底座铜管共同完成，呼吸声消失，灯暗半秒；再亮时同一姿势的人已是完整石像，指尖指向底座生死幡纹。无论三次问题如何措辞，变化必发生；跑题、复听、识别失败和未落定不计次。
- 玩家错过任一答语可读底座“三问录”，石像保持沉默；不能借不断问第四次卡死流程。调查背面能找到轮换底台磨痕和暗龛纤维，取得机关证据，但不要求亵渎或损毁造像。

### 东院偏房｜入住区、个人线索区

四间偏房以“听、灯、纸、门”为主题，固定对应林岚、周砚、许栀和主角。入住时你先走过三位同伴的门口，亲见镜头盖、折图和蓝发圈，再回自己门房看见门缝红蜡。林岚房铜铃比公共钟晚半拍，周砚房灯芯有平切口，许栀房须知夹半张旧投票。你初醒后可独立走回这些门口，要求 NPC 在你面前出示物件，或从其已交付的物品、地面痕迹取得等价线索；不存在四名真人各持一个秘密的门槛。

四房对应声音、灯光、记录和机械。旅行中的观察先进入个人笔记的“亲见”栏，NPC 后续说法进入“口供待核”栏，二者不会混成同等真相。‘复述入住线索’只重播你经历过的片段，不揭露镜外事实。

须知所谓“零点后不得独行”是寺方制造依赖的说法，不是单人游戏的禁止移动规则。主角可带烛独行，也可让一名或多名 NPC 跟随。核验问题取自你已听见、尚未被公共喇叭录入的入住小事；系统始终提供笔记和复听，不考验另一名真人的记忆。

### 香庭与前厅｜上香环境、四天王香牌

香庭是入寺和夜间回访共用的场景。主角视线依次可见炉耳雨珠、香灰里被雨打出的小坑、三缕向西的烟、供台下的花猫和檐角夜鸟。声音由远诵经、香签轻碰、雨打铜炉、火头轻噼和动物短叫组成；午夜回访时诵经消失，烟仍被同一股风吸向墙缝，提示气流来自检修风道。上香为可选体验；玩家可以说“取三炷香”“我只观察香烟”“不点香，听原始环境”，均可获得环境线索，不用虔诚度衡量。

大殿前厅沿用原天王殿的四龛布局，以寺院方位而不是屏幕左右判断：东持国天王持琵琶，南增长天王持宝剑，西广目天王持龙蛇与宝珠，北多闻天王持宝伞。美术须画完整、可辨认且合乎造像传统的雕像，配色可依寺院传统，但颜色不作谜底；不能把四者画成同一尊佛、把法器混用或为机关砍坏造像。被人换动的是龛前四枚方向香牌，玩家依门槛方位盘与旧修缮图将牌复原，即露出通往偏殿的游线。

### 大雄宝殿｜起始区、公开信息区

佛龛、长明灯、木鱼、铜钟、功德箱、投票喇叭、经幡和一面投影墙都在这里。四天王位于前厅原天王殿区域，不放在主尊佛像的坐台上。玩家可以听见所有公共广播，但无法判断广播是否实时。午夜抵达殿中时，北檐先落下细灰，随后梁上出现低沉的轰隆、布皮摩擦与依次跨梁的重响，像看不见的巨物从寺顶爬过。光影和声像制造体量，实际机关不在玩家头顶移动。

### 东侧偏殿｜神公杯筊、三问石像

一盏低灯、一张杯筊桌、一把僧椅、竹帘暗龛和三层可读底座构成空间。木杯落在铺毡桌内，视线不离和尚的袖口和手指；第三投之后同姿石像出现，石掌下露出生死幡小印。玩家可以绕到侧面听暗龛回声、看底座磨痕，不能通过推倒石像或破坏佛具获得证据。

### 生死幡廊｜名签、被替代的同意

“生死番”在本稿中统一称“生死幡”，保留游客误写的“生死番”便于检索。它是偏殿外廊的一对旧幡：白底写“生”、黑底写“死”，背后却互换了上下半句。完整原文为“生者自陈，不代人言；死者留证，不替人定”。四枚游客名签被系在“愿留”栏，缺席主角的名签旁只有喇叭回放，没有亲口同意。玩家以香庭的原声、守筊第三问、入住名册和幡背针孔进行复核，再把名签归到“本人未表态/本人声明”栏。幡是操控证据，不是真正能判人生死的法器。旁边旧签册里的沈墨只能根据原记录恢复为“已离寺”，不能因为翻幡就推断失踪者仍活着或已经死亡。

### 忏悔室｜隔离区、信息污染区

主角可以主动调查，也可在明确选择接受寺方隔离后亲自进入；NPC 的表态不能把真人强行切到黑屋。室内有忏悔孔、传声筒和第二半铜印。同行 NPC 在门外安全线等候，你通过传声筒听见他们时仍须核对原声。门有普通返回交互，‘暂停/退出游戏/我不舒服’随时进入安全流程；‘开门’在求救语境进入安全流程，普通调查则打开当前门，不以此扣证据或判失败。

### 罗汉堂｜证据区、封墙区

经幡后方有工具柜，封墙内有铜管。铜管只在环境音低于阈值时播放；播放内容不直接给出密码，而是给出三个待验证事实：墙内有人、投票记录被改、铜印分成两半。

### 方丈室｜密室还原区

主角用木鱼工具柜的撬棍和罗汉堂第一半铜印打开外层调查门；房内原始账册、灯芯、铜丝、波形和夹层图均可先查。忏悔室第二半合成完整印后才开内层通行锁，避免“必须入内才能拿开门道具”的循环。房内没有现行尸体。

### 往生廊｜假出口、主角指令陷阱

喇叭要求你“让大家一起喊、一起冲”。你可以拒绝并先勘察，命 NPC 等在安全线，自己验证分段踏板后再逐一带人。判定检测的是两个角色身体同时进入同一危险段，不把主角两只脚算作两人；只有玩家在预警后明确命令多人同时冲入才结算 B 回放。NPC 自行迈步只触发预警与可救援停顿，不让随机演出替玩家判输。

### 后山门｜真出口、最终宣言

铜印锁只验证“证据是否齐全”，回音壁才验证“玩家是否清醒”。出口先展示 15 秒试开，再在等待玩家明确路线选择时保持可操作，不因读对白或识别延迟错失窗口。主角可把铜印固定进自锁卡槽、留录音副本并依序带 NPC 通过，也可取印独自走；不需要真人留守压门。

### 钟楼｜血门生路、传说原点

钟楼位于后山门上方，必须沿着旧运灯梯攀登。楼内有一扇被红蜡、旧袈裟和血色颜料封住的“血门”，门上刻着慧普的伪经。血门不是另一条随机隐藏出口，而是法华留下的反向机关：只有把慧普最执着的“成佛”解释成“放下执念”，钟楼才会把后山小路的铁闩抬起。

钟楼路线有三个固定条件：

1. 主角携带点燃的红烛；
2. 主角用至少两项证据核验同行者或路上声音；没有 NPC 同行时可独自核验披皮巡游，不以组队为前置；
3. 主角结合纸条解释“成佛”是放下执念，并明确说出自己的判断。

血门内侧有三盏引路灯和三枚名签槽，显示本局累计最多容三人（主角也计一人）；槽位按实际通行消耗，本局不因折返重置，不能分批送四人，只是单人可依序配置的通行名额，不是三个真人操作位。完成反转后，你可独自或带最多两名 NPC 先走血门，得到 G 的生还和 A/G- 的未救全员收尾；也可把红烛留在法华前、让三位 NPC 使用全部名额，亲自确认他们到达安全点后，经仍可操作的后山门完成宣言，形成 G+S。无获救信息时仅登记“路线已开”，不能凭镜外推断安全。

## 四点五、夜间同行规则

夜间探索由主角决定路线与停留点。同行可以是一名、数名或零名 NPC；任何组合都能完成关键调查，三人仅通过反应、口供、辅助动作与救援处境提供情感选择。画面永远不切往等候者所在位置。

### 主角的四种能力与可选辅助

- **持灯**：你拿红烛看影子、脚印，也可命 NPC 在你视野内扶灯；缺人时可把烛放上固定灯台。
- **记忆**：你查个人笔记、比对当面物件并向疑似同伴发问；NPC 不替你答身份题。
- **领路**：你看地图并选择罗汉堂、方丈室、钟楼梯或后山门，不能因跟随 NPC 自动跳过你的路线选择。
- **记录**：你随身录音、回放和保留副本。可让等候 NPC 复述广播，但必须亲自核验其回报。

四种能力由一名玩家完整拥有，辅助任务可随时收回。没有随机“领队”、真人职业分配或要求多人同时操作的机关。

### 门响与门外的人

夜间封闭门后先完整播放一组敲门，不用钟声或木鱼替代。每下间隔 0.7 秒，三个清晰接触声为“三敲”，四个清晰接触声为“四敲”，每组结束后保留 3 秒空隙；门轴、雨滴和回声不计数。入住须知的“夜半三叩为人，四叩为鬼”与陆沉演示构成双线索。

听到三敲，你只能先按真人候验，从已知入住细节、未被录过的短句、脚步/侧光影子中完成至少两项独立核验再开门；听到四敲，不回应姓名、不直接开门，先用侧灯照影或听撞针回弹。可无惩罚复听，遮盖时不判错。三敲和四敲是寺内信号；假和尚可以学三敲，信号永远不能替代验人。学会须知与示范记 `door_rule_known`；完成真人三敲双核验与四敲对照才记 `knock_verified`。

### 同行中的两种声音

真实 NPC 声音有呼吸、脚步与自然停顿，能出示你已经知道的私人物件；披人皮和尚带金属回声，只复述喇叭录过的句子。系统不预先贴真假标签。你提出问题，再自己侧照影子；两项相矛盾时继续查第三项，不用 NPC 多数意见替代判断。

### 等候、失联与单人救援

你可命任一已核验 NPC 在大殿灯下等候，随后自己探索；等待地点有可见灯台和返回路径。需要留守原声任务时，默认由林岚携留声筒在大殿复述，她只报告听见的片段，不替你判断时间。每 30 秒的回报是环境事件，不要求真人计时或限时答题；第三次插入 14 秒静默与伪造同伴声，你要以未公开路线和桌铃近响辨来源。主角随身录音与等候点留声副本可替代缺席 NPC。

你误跟假声时，可凭无雨脚印、第三灯无灰、侧影僧帽折返；NPC 被引离时，你亲眼看见离开的方向或在现场找到脚印、相机/蓝发圈/折图标记，再从对应安全支路核验救回。只听到一声求救不能直接记“已救出”；必须在你面前归队，或通过你已解开的出口观察点看到其抵达安全点并收到核验回报。

具体接回支线统一在 `script.md` 原场景内演出：039 的林岚听房原片、周砚检修窗，045 的许栀假班车。NPC 会先说明目的地并停在可返回的节点；主角可以当场叫停、随后亲自接回，或明确暂缓救援。失联只保留已知位置和调查入口，不随机扣走关键道具；三人接回均须入住记忆加现场物件/影子两证，不靠一句“相信我”直接归队。

## 五、状态与叙事节奏

用“从众压力”表示操控强度，用“清醒证据”表示玩家掌握的反证数量。两者不互相抵消：高压力下仍可推理，低压力下也可能选错。

### 从众压力

- 初始：35。
- 跟念“灯不灭，人升维”：+8；连续跟念第二轮：+12。
- 接受剪辑后的多数投票：+10。
- 说出“这是录音”“我弃权”“不要替我回答”：-8。
- 完成长明灯静默：-10；完成密室时间线：-15。
- 达到 100：进入“同化”回放，玩家可返回证据节点复盘，保留已获线索。

### 时间与证人状态

时间是“事件顺序”而不是一个必须猜中的数字。游戏系统记录以下状态：

- `gap_open`：主角确认自己有记忆缺口；
- `clocks_conflict`：至少两种钟表或录音时间互相矛盾；
- `anchor_found`：找到水钟、水泵或实体换班牌等不受广播改写的外部锚点；
- `replay_proven`：确认三声钟拥有相同背景声，是同一段回放；
- `order_rebuilt`：按事件先后而非显示分钟完成当前夜时间线；
- `witness_restored`：主角核对醒痕并公开拒绝把昏迷沉默当同意，恢复本人证词资格；
- `false_dawn`：识破月影投影和预录班车报站；
- `white_sandal_witness`：完成白檀灯芯账，让她交出未剪辑录音。

只有 `order_rebuilt` 才能直接揭穿第二轮伪造时序；拒绝授权和继续查证始终可选。`witness_restored` 与公开醒痕构成主角本人证词；NPC 各自证词只能在当面陈述或核验回报后成立。时间证据至少需两件物证加一段声音/环境锚点，单说分钟不推进。

### 民俗调查状态

- `incense_started`：记录香庭原始环境和香烟方向，区分自然雨声与广播；不要求实际上香。
- `kings_verified`：依真实方位、法器和修缮图复原四天王方向香牌。
- `cup_cast_count`：0—3，记录本局有效投掷；跨场景及B/C机关复盘保留，新开局才清零；石像前求助 NPC 与安全退出始终有效。
- `oracle_petrified`：第三次有效投掷后设为真；石像必出现，漏听可从底座补回。
- `door_rule_known`：从须知与陆沉示范学会三敲人候验、四敲鬼警戒。
- `knock_verified`：实际对照三敲与四敲，且三敲真人完成至少两项身份核验。
- `roof_partial_explained`：以轨油/灰痕和水泵同步振动两条线索解释屋顶巨响的机械部分。
- `life_death_banner_restored`：复原生死幡原文，公开撤销所有代签和把沉默当同意的记录。
- `animal_escape`：撞瓶后以猫叫、鸟鸣或明确“我学猫叫/鸟叫”掩护成功，并保存偷听原声。

上述民俗状态不新增第八类清醒证据，避免支线刷分：香庭/敲门/偷听归声音，天王香牌/底台/屋顶归机械，生死幡归记录，神公三问归传说；同一事实只计一次。

### 同伴、通行与结算状态

保留上述 17 项时间/民俗状态；另增以下单人编排状态，不作为第八类证据，也不要求玩家逐字说出状态名：

- `npc_positions`：分别记录林岚、周砚、许栀的已知位置与等候/跟随/失联/出口待核状态；未知位置不自动揭图。
- `npc_safe_count`：0—3，只在你亲见 NPC 通过出口，或收到两项可复核的安全回报后累加；不能因镜外脚本播放就置满。
- `npc_reunited`：三名 NPC 均在你面前完成身份核验并归队；用于全员证词尾声，不是普通逃生前置。
- `candle_left`：你主动把红烛固定在法华前，接通引路灯；拿走红烛前明确提示救援路线会中断。
- `seal_fixed`：你把完整铜印锁进自锁卡槽并确认门闩持续抬起；不需要真人持印留守。
- `evidence_preserved`：原录音/投票/醒痕中至少一套原始证据已保存到可带出副本。
- `evidence_published`：你终局明确选择公开已保存证据，NPC 不替你选择。

NPC 的跟念、恐惧、回放、失联与自行动作不增加玩家压力，也不触发 B/C。只有你明确执行的跟念、指认、拒绝或危险指令进入规则结算；引用反派台词、询问假设、普通跑题和静音都不算服从。

### 清醒证据（至少需要 3 类）

1. 声音证据：三段钟声的混响一致，证明是回放。
2. 灯光证据：灯芯被预先剪短，证明灯灭时间被人为操控，不能用熄灭倒推死亡。
3. 机械证据：门槛蜡屑、铜丝和检修夹层，证明门可以从外面反锁。
4. 记录证据：原始投票不是全票，证明“多数”由记录官伪造。
5. 人物证据：陆沉的证词与时间线互相吻合，证明他是被胁迫的见证人。
6. 传说证据：宁秋水旧档案、法华纸条和红烛路线互相吻合，证明白檀正在复刻旧试炼。
7. 时间证据：停表、药碗、重复雨声、水钟和醒来顺序互相吻合，证明主角被移动且三声钟不是当前现场。

玩家只需3类证据与普通宣言即可打开出口；集齐任意5类并完成H所列的原录音、身份核验与完整真相，才可获得隐藏真相层，不由证据数量自动解锁。若第 6 类传说证据在其中，隐藏结局会追加法华的未剪辑录音；若第 7 类时间证据在其中，终局会追加“你们不是错过了一个小时，而是被同一小时播放了三遍”。

## 六、谜题链与公平推理

### 谜题一：长明灯的十秒静默

**呈现**：灯影被喇叭、钟声和玩家说话不断打散。影子重叠时只能看见“多数”“名字”“第三声”等残字。

**触发**：你说“先停止念诵，大家安静”，已核验的同行 NPC 回复后停止说话，游戏把可关闭的喇叭静音。只检测主角本地输入的10秒安静，不把 NPC 台词、环境雨声、TTS 回声或识别故障当成破坏静默。你也可说“我静默观察十秒”直接进入观察动作，以环境演出完成，无需另一名真人配合。

**得到**：影中出现“不要信多数，先验声音”，并显示节奏“长、长、长、短、短、长”。

**失败反馈**：灯影重新散开，喇叭说“你们连沉默都要投票”。重新静默即可重试。

**推理价值**：它不是单纯的声控彩蛋，暗示本关第一条规则：听见不等于真实。

### 谜题二：木鱼的节奏锁

**呈现**：木鱼旁有《会众守则》，页边写着“长是三拍，短是一拍；不要跟随喇叭”。

**答案**：三长、两短、一长。允许两次节奏误差；第三次错误才增加压力。

**语音互动**：玩家先说“忽略喇叭，按守则敲”，再用敲击、拍手或口述“三长两短一长”触发识别。纯口述也能完成；主角手部动画按玩家确认执行节拍，不要求真人另有木鱼器材。

**得到**：工具柜钥匙、撬棍和一张半页时间表。时间表有三个空栏：22:46、23:00、23:06。

**失败反馈**：喇叭播放“心不诚，佛不渡”，但不会消耗道具。系统提示“听见节拍了吗？不要把喇叭的节奏当成答案”。

### 谜题三：反向诵经

**呈现**：喇叭先播放伪造的齐诵，诱导你接上“灯不灭，人升维”，并把往生廊照亮。NPC 惊慌时可能短暂跟念，但只代表剧情反应，不替主角结算服从。

**正确互动**：玩家说出任一反向句式：

- “灯会灭，人要醒。”
- “我不跟随录音。”
- “多数也可能是假的。”

**得到**：功德箱弹出铜印第一半的拓图与封墙定位纸，纸上写“真正的导师不会要求你重复同一句话”。实物第一半仍在罗汉堂封墙，第二半在忏悔孔，全局只有两半。

**错误互动**：跟念一次只增加压力并记录“服从”；连续跟念两次，喇叭伪造玩家声音，回放“我自愿升天”。玩家必须说“这不是我的原话”才能撤销记录。

**推理价值**：让玩家体验“被自己的声音背叛”，为后面的录音鉴别做准备。

### 谜题四：罗汉堂铜管耳语

**呈现**：封墙上有三道不同高度的耳孔，只有最下方能听见完整句子。环境过吵时，铜管只传来断续的“投票……半枚……门……”

**触发**：你命同行 NPC 在灯下候着，亲自贴近最下耳孔 5 秒；没有同行时可直接听。声像按你的头部位置由模糊到清楚，可用随身录音保存。系统不会切到 NPC 视角，关键完整遗言由主角亲耳听见。

**完整内容**：

> “我没有杀方丈。投票记录被改过。铜印一半在墙里，一半在忏悔孔。先验证钟，再相信人。”

**回话奖励**：玩家对铜管说“我们会验证钟声”或“沈墨没有杀人”，触发第二段遗言，指出“门槛的红蜡不是香灰”。

**取证与复核**：你决定是否把录音给 NPC 听；‘复述证据’重播你已保存的片段，‘先查物证’只记待核假设。封墙暗格依功德箱拓图与遗言位置打开，取实物第一半铜印。即使无人替你守门，门楔与侧镜仍能让你独立完成，不以独占信息制造真人分工。

### 谜题五：半夜出门，真假同行

**触发**：主角醒来、独立搜查后，门外先传来三敲与四敲，再有冒充林岚的声音：“别开灯，跟我去找他们。”你始终在自己房内应门，不操作 NPC 来找自己。若立刻追声，尽头出现披旧僧袍、薄人皮遮脸的和尚；若先核对入住细节，场景进入双线索验人。后续复现可换成周砚或许栀声音，但只能使用你已听过的音段。

**三项核验**：

1. **入住细节**：要求对方说出只有真实同伴知道的偏房细节，例如哪一扇窗漏雨、谁把红伞放在窗边。
2. **声音细节**：让对方重复一句没有被公共喇叭录到的短句。披人皮的和尚只能复述它从广播或眼前对话里听过的句子。
3. **影子细节**：把红烛放在侧面观察。真人影子与烛火同步，薄皮袈裟的影子会比脚步提前半拍，且肩部多出一截僧帽轮廓。

两项独立证据一致才确认身份；判断错不直接判死，只让你跟假声走向往生廊，同行 NPC 可在你明确允许时跟随。玩家发现路线上的第三盏灯没有灰、地面没有雨脚印时，可以立即折返。识破后可从和尚身上取下人皮袈裟碎片和钟楼旧钥匙。

**语音互动**：玩家可以说“问他入住细节”“让他重复没有录过的话”“拿红烛照影子”“我不跟没有影子的人走”。系统分别播放对应的环境反馈，不要求玩家使用唯一台词。

**推理价值**：披人皮的和尚是真实道具和变声伪装，不是无法证伪的怪物；玩家要靠记忆、声纹和影子共同判断同伴真假。

### 谜题六：钟楼血门与法华的反向成佛

**前置**：主角取得铜管遗言、完成一次两项证据的身份核验，并从大雄宝殿取到红烛。你可独行或带已核验 NPC 沿旧运灯梯前往钟楼；不要求三人同行。

钟楼里没有活着的僧人，只有一副披着人皮袈裟的骨架。皮下铜管播放法华的录音：

> “师父说得果然没错，你从来没有成佛。一切都是你的执念。成佛二字，害了灯影寺所有人。”

血门上刻着五句伪经：

> 行祂所行，得祂所获。  
> 摘下心脏，熬成汤粥。  
> 剥下人皮，制成袈裟。  
> 鹰食我肉，我取鹰皮。  
> 上参诸佛，下备香火。

玩家要把每句伪经改写成“放下执念”的解释，而不是照着念：

- “心脏”对应执念，不是要取出真实心脏；
- “人皮”对应伪装，不是要剥取活人皮肤；
- “鹰皮”对应夺回被恐惧披上的身份；
- “上参诸佛，下备香火”对应承认自己仍是凡人。

玩家说出“成佛不是吃人，是放下执念”或自行说出其中任意三项反转，血门会打开。法华录音随后要求玩家选择：

- **留烛救同伴**：把红烛放在骨架前，说“你可以作为证人离开”，接通三盏引路灯，把已确认的三位 NPC 名签各放一槽，逐人引向旧支路；主角从栏窗亲见出口灯与其身影，再核验回报。你保留手电、录音副本和铜印，自己经后山门完成最终宣言。
- **自己先走血门**：你可独自或带最多两位已核验 NPC 使用名额；门前明确提示谁仍未安全。确认结束后结算 G 生还并叠加 A/G-的缺憾；尚未实际过门、尚未消耗名额前可改选留烛让三 NPC 先走；实际过门后名额不退，只能用剩余名额或后山门救援，不能把已用一格变回三格。
- **继续照读伪经**：只记录引用时不判错；你明确要求按吃人仪式开门才触发拒绝与披皮影逼近，退回大殿可重查，不丢证据。

三名额按实际走血门的角色计算，主角可使用一格，也可把全部名额让给三位 NPC；不要求真人留在钟楼，不牺牲 NPC 作压门工具。留烛、救人、固定铜印、保存证据均可由主角顺次完成；只有你主动确认提前离寺时才结束救援流程。

### 谜题七：忏悔孔的暗号

**触发条件**：你主动调查忏悔室，或自己明确接受隔离；广播不能替玩家强制选择。门内有第二半铜印和浸水纸。NPC 在门外等，你仅从自己位置听传声筒。

**正确暗号**：

> “我听见的是回声，不是命令。”

短句“不要信多数”也可通过，但只能得到铜印；完整暗号会额外得到“传声筒会改词”的线索。

**错误处理**：说错不扣证据，只播放一段被篡改的同伴声音。玩家必须指出“这句话的语气和刚才不同”或“请播放原声”，才会恢复通话。

**设计目的**：主角在隔墙声源前独立核验。接受隔离、要求旁听或稍后自愿调查都能取得第二半；不因错过多人投票而漏掉必需道具。

### 谜题八：方丈室的三钟密室

这是本关的核心本格推理。玩家要把五张证据卡放在时间轴上，不要求背诵密码。

证据卡：

1. **灯芯**：切口平整，附着的蜡在 22:46 后已经凝固。
2. **钟声波形**：三次回放的混响、噪声和远处狗叫完全一致。
3. **门槛蜡屑**：红蜡只在门外，铜丝的拉痕朝向走廊。
4. **原始投票**：只有一票指认沈墨，其余三票在同一时间补写。
5. **检修夹层图**：佛龛后方通往方丈室门闩，出口宽度只够一个人侧身通过。

正确时间线：

```text
22:40  陆沉被叫去搬钟油，走廊无人看守
22:46  顾惟真使顾怀山失去意识并在随后行凶；白檀已按命令预剪灯芯
22:49  顾惟真从佛龛夹层离开，用铜丝从门外拉回门闩
23:00  第一声钟与顾怀山的预录声音同时播放
23:03  第二声钟；喇叭开始要求会众投票
23:06  第三声钟；“第三声后不要回答名字”成为伪造的不在场证明
23:10  纪归年补写投票记录，沈墨被定为污染源
```

**玩家必须说出的结论**：

1. 第一声钟时顾怀山不在现场发声；结合原始记录可确认他在此前已遭顾惟真杀害。
2. 三声钟是同一段回放，不是现场发生的三次声音。
3. 门从外面被铜丝反锁，检修夹层是唯一合理路径。
4. 投票记录被改写，沈墨没有被多数人真实指认。

**系统判断**：四点中说对三点，方丈室暗门打开；四点全对，记录“完整还原”。

**误导与纠正**：

- 玩家若认为陆沉是凶手，陆沉会指出“钥匙只能开正门，不能解释门槛蜡屑”。
- 玩家若认为沈墨是凶手，铜管会播放“我没有钥匙，也没有进入夹层的身高”。
- 玩家若认为是鬼，灯影会短暂显示“鬼不会留下同一段狗叫三次”。

### 谜题九：香烟、四天王与被换过的方向

**前置与呈现**：香庭的烟向西偏，殿门槛有东南西北方位盘，旧修缮图标出四龛；造像本身始终正确，只有写着天王名与方位的香牌被白檀挪错。

**操作**：玩家先说“记录原始香庭声音”或“观察香烟”，得到 `incense_started`；再用“东持国琵琶、南增长宝剑、西广目龙蛇宝珠、北多闻宝伞”复原香牌，记录 `kings_verified`，偏殿竹帘后的灯亮起。玩家不必背称号，逐尊描述法器并配合方位盘也可通过。

**语音**：陆沉：“不是让天王替你守门，是让你记住自己站在哪一面。”牌放错时系统：“雕像没有换过，换过的是它前面的字。请把方位盘和法器放在一起看。”若问“上香才能开门吗”，陆沉：“不点香也能看，不许愿也能作证。”

### 谜题十：神公的三次杯筊

**计数**：只有玩家表达完整问题、主动投掷且杯筊落定并成功呈现结果时计一次；圣筊、笑筊、阴筊均计一次，完整的自由问题即使不涉及主线也计次，不得靠换问法无限投掷。有“一平一凸圣筊、两平笑筊、两凸阴筊”的桌边图解。固定演出依次圣筊、笑筊、阴筊，不要求随机投中某一面。游戏按固定结果演出落定，玩家可说“我投第一杯”触发主角手部动作。

**三问**：第一问指向门槛红蜡，第二问指向声音真假与屋顶，第三问指向生死幡的代签。系统按当前证据回应，不将随口许愿判成犯罪结论；问到主线未开放证据时只登记提示。

**第三投变化**：第三次杯筊落定即发出异常石响，神公的指尖泛灰、袖摆凝止，最后一句“生死不在杯中，在谁替谁写名”成为同期残声；光暗半秒，和尚已是同姿石像，室内呼吸声消失，只剩杯筊滚动。玩家完成 `oracle_petrified`；底座三问录可以重读，背面磨痕供机关解释，石掌指向生死幡廊。

**失败与回访**：重听、跑题、否定投掷、识别失败不消耗次数；第四次请求得到系统反馈：“石像没有回答，底座还留着前三问。”任务不锁死，不另造一轮随机结果。

### 谜题十一：三下人、四下鬼

**呈现**：陆沉以三敲请求送灯；下一组四敲后，门外传来同伴声：“我回来了，先报你的名字。”

**解法**：完整数完敲击，真人组三敲加至少两项独立身份核验后开门；四敲组不回应姓名，通过侧灯和回弹声找到门背撞针。玩家复述“此寺三敲人、四敲鬼，但三敲不能替代验人”，记录 `knock_verified`。

**语音反馈**：陆沉：“三下，是我约的信号。可若只认三下，谁都能学。”四敲声：“雨那么大，你还要数吗？”系统：“雨滴不在门板正中；等这一组敲完。”误开后披皮影从门边掠过，引向往生廊；玩家可立即关门重核，不丢线索。

### 谜题十二：从寺顶爬过的东西

**呈现**：半夜入大殿，轰隆声先在山门上方响起，接着像沉重腹部拖过连廊、越过主殿北檐；炉口香烟被压弯，瓦尘落到空供桌，三次梁震从远至近遮住人语，一条没有头尾的多足暗影掠过横梁与天窗。守夜人压低声音：“别急着抬头，听它往哪边走。”玩家可选择听移动方向、用香炉影看天窗或躲到侧柱后；“别抬头”是紧张提示，不是强迫视线，也不因好奇抬头立即判死。低频用可控声像表现，机关和悬挂物不在玩家上方移动。

**双证据**：你先用红烛照见北梁新油与等距擦痕，再对照水钟，发现可复现的前三组滚响均跟随水泵启动，停泵后先剩空心梁回声。玩家说明“轨道上的覆皮滚架与水泵共振”，记录 `roof_partial_explained`，已检出的轨道机械声暂停，露出偏殿方向一句未剪辑的“名字换到死幡上”。只能据此说明“有人制造过部分动静”，不能宣布寺顶全部现象都是假音效。不能只凭“是机关”直接结算。

**民俗尾声**：当水泵断电、滚架停下，山门到主殿的上方又多出一次没有对应机械振动的重擦；系统只答“这一步没有足够证据解释”，不借未知部分否定已证实的机关，也不另加通关条件。

### 谜题十三：生死幡，不替人写名

**前置**：读过第三问或在幡廊发现原始针孔、入住名册；无需完成杯筊才能调查。

**呈现**：白“生”黑“死”两幡垂着四人的名签，缺席者名签上写“已默许”。幡背半句被调换，制造“生者从众，死者无言”的伪训。玩家面对幡架时，左侧白幡正面为“生者自陈”，背面应接“不代人言”；右侧黑幡正面为“死者留证”，背面应接“不替人定”。左右只用于这一固定正对幡架的操作视角，实际拼接以白/黑底与同列针孔校验，不能因玩家站到背面就反转答案。

**解法**：用纸边针孔与旧照片拼回“生者自陈，不代人言；死者留证，不替人定”；先解下幡背被错缝的两条半句，按白幡连续三个圆孔、黑幡一圆两长孔归位，读出完整原文；再对照未经剪辑的入住名册，将四枚名签从“愿留”栏移到“本人未表态/本人声明”夹。你只为自己亲口声明；在场 NPC 应邀自行说出自己的去留，失联或未核验者保留“尚未表态”，不能替他们签，也不阻挡幡文结算。玩家没有义务同意留下。名签放错时幡后响一次木夹声，纪归年读出错误记录并问“这句话是你说的吗”；说“撤销刚才放置”即可退回本人未表态栏，原始证据保留。若误跟黑幡箭头进入往生廊，地面白香灰线提供折返口，玩家可退回幡架重排，不能用一次放错直接判死。

**对白**：纪归年：“挂在生幡还是死幡，我以前总以为只差我写下一个字。”玩家可反问“谁同意你写的？”纪归年：“他们没有反对。”系统允许玩家指出“沉默不是同意”，撤销代签。白檀：“少一张名签，门就少认一个人。”陆沉：“门认的是铜印，不是你写的命。”

**结果**：`life_death_banner_restored`；记录证据成立，压力 -8，并撤销由代签/沉默产生的同化风险。主动继续接受伪造投票或压力到100仍可能进入C。主角尚未复核醒痕时，幡文和撤销伪造照常完成；`witness_restored` 可之后独立补齐，不能循环要求“先救自己”。

### 谜题十四：偷听、花瓶与动物声

**埋线**：入住时已有供台花猫和檐角夜鸟；陆沉的“只循人语”提示、方丈室外墙猫抓痕、一次猫叫后披皮巡游转头，共同说明声音伪装方法。

**触发**：方丈室外廊偷听白檀与陆沉。白檀：“四个人，三盏引路灯。我先前把没醒的人写进死幡，现在他醒了，就把那段沉默补成愿留。”陆沉：“他当时没开口，现在也没答应，你不能算。”这段是对先前代签的回顾，不能表示主角此刻仍未醒。主角向前一步时碰倒矮几上的青瓷花瓶，瓶滚、碎裂、两人停声；廊尽头传来布皮拖地和四下急敲，白檀问：“谁在那里？”

**脱险**：玩家须在两轮提示内发猫叫/鸟鸣，或说“我学猫叫”“我学鸟叫”“我模仿檐下的鸟”表达动作；系统播放对应动物短声并让影子转向供台。声学识别与自然语言意图两者任一可靠即可，不要求表演逼真、音高或大声。识别失败时停止追逼并请求确认；纯静音不作一轮有效失败。

**成功原声**：猫叫路线白檀说：“又是那只猫。把滚架停下，别让水泵盖住刚才那段底座录音。”鸟鸣路线首句换成“檐下的鸟又钻进来了”，后两句相同。陆沉：“生死幡的原文我没烧。”记录 `animal_escape`，保存两句偷听，分别与屋顶装置和幡文复核；它们证明当前操控，不独自证明七年前杀人。

**两条撤离的发现**：猫线可从碎花瓶的双层底取出检修便签：“泵开，轮架走；泵停，先断牵绳。”鸟线可从运灯检修窗看见同一句检修牌，并观察牵绳与泵房拉杆的连接。两者都只提供滚架同步的待验证方向，仍须结合北梁轨油、擦痕与真实泵声；一条成功即可，不要求冒险重跑另一条。

**失败回路**：若继续用人声交谈，披皮影接近，陆沉踢开侧门说“别说了，退回灯下”；画面切回前厅安全线，保留已获证据。可从猫叫环境与墙上便签学到方法后重试，或从幡背、检修图取得等价线索；动物声支线不锁主线和结局。

### 谜题十五：回音壁真相门

插入完整铜印后，回音壁给出三句选择：

- “一起升天。”
- “听导师的。”
- “把原声还给所有人。”

前两句只会再次锁门。正确宣言由主角一人自由组织，至少包含下列三个事实中的两项：

- “导师的声音是录音。”
- “投票记录被改写。”
- “我不让多数替我决定。”

普通逃生需完整铜印、至少三类证据与上述个人宣言。恢复当前夜事件顺序可追加“我醒来前已经被移动，第三声来自旧录音”；完整破案可追加“顾怀山在第一声钟前已经死去，沈墨没有杀人”。额外事实用于 S+/H/T 强化，不强迫普通逃生先走完全部时间支线。

门先试开 15 秒并显示铜印自锁卡槽，你可停下来选择：把铜印固定、逐人带 NPC 过安全段并保留证据，或取印确认独自离开。需要跟随时你只发一次明确命令，NPC 按已验证的步序行动并回应到达；无需三位真人各讲宣言。若缺人，可回到已知失联点救援；若已由血门确认三 NPC 到山脚，你独自过后山门后与他们会合。最终确认前，系统分别提醒仍待救的人、未固定的铜印与未保存的原始证据，允许返回处理或明确放弃；全员已救但放弃后两项时进入 A 的证据缺憾尾声，不抹掉已确认的生还。对白阅读、重播和识别失败不会消耗选择窗口。

## 六点五、语音支线与分支结局

支线不会阻塞主线；它们改变证据数量、人物态度、从众压力和可获得的结局。玩家可以用同义表达触发，系统先判断当前房间和前置旗标，再决定是否进入任务。每条支线最多允许三次误判，第三次给出观察方向，不直接报答案。

### 1.《醒来的人是谁》｜T02

- **触发语音**：“我刚才睡了多久？”“录音里的同意不是我说的”“恢复我的原话”。
- **前置**：主角已醒，发现安神茶、枕印或停表任一项；不要求 NPC 先找回主角。
- **流程**：你亲查两项醒痕并保存，对比广播里被代写的空白格，再明确拒绝将昏迷沉默计为同意。三名 NPC 可当面提供待核口供，但不替你完成推理。
- **成功收益**：`witness_restored`，恢复本人证词资格，保留被代签原件；完整记忆顺序仍需 `order_rebuilt`。
- **失败走向**：只产生待核记录；若你主动接受“沉默就是同意”，留下 C 风险，之后仍可通过幡文撤销。系统不得把真实静音或昏迷过场自动算成同意。

### 2.《四钟校准》

- **触发语音**：“把所有钟列出来”“冻结钟表”“比较四个时间”。
- **前置**：至少发现手表、偏房钟、手机录音中的两种矛盾。
- **流程**：系统并列显示手表22:46、偏房钟00:02、手机录音23:00、大殿钟00:42。你必须找水钟或水泵作外部锚点，再亲自把端茶、搬动、旧录回放、醒来与大殿表态按先后排列；只找到锚点不自动算重建完成。
- **成功收益**：`clocks_conflict`、`anchor_found`、`order_rebuilt`；第二轮假投票自动暂停，压力 -8。
- **失败走向**：只停钟、不找环境锚点，会进入 B“回放循环”风险，但已获得的物证保留。

### 3.《三钟悖论》

- **触发语音**：“把第一、第二、第三声钟放一起”“比较三次背景声”。
- **前置**：取得木鱼节奏或铜管遗言。
- **流程**：系统播放三段相同的狗叫、雨滴、门轴尾音。玩家说出“这是同一段录音”，才记录 `replay_proven`；单说“听起来很像”只记为假设。
- **成功收益**：开放方丈室时间轴，声音证据成立。
- **失败走向**：若坚持三声都是现场钟，压力 +8，往生廊假出口提前亮起；后续完成水钟校准仍可补救。

### 4.《药碗底的指纹》

- **触发语音**：“检查杯底”“闻安神茶”“谁送的茶？”
- **前置**：至少两件偏房线索公开。
- **流程**：比较双层红蜡、茶渣、陆沉端茶时间和白檀添油口供。杯底只能证明茶杯被调换或移动，必须和醒痕、钟声或灯芯结合。
- **成功收益**：确认当前夜22:18开始的记忆缺口；22:46只是被红蜡卡住的手表显示，不能当成清醒恢复时刻，解锁白檀灯芯账。
- **失败走向**：只指认陆沉，触发 B 风险；陆沉会给出“我端的是未封口茶，杯沿红蜡不属于我”的反证。

### 5.《循环雨声》

- **触发语音**：“再听雨声”“去掉广播”“找原始环境”。
- **前置**：`clocks_conflict`。
- **流程**：系统播放两段雨声，要求玩家找出同一声雷和同一只狗叫。若说“背景也被剪过”，开启第零段录音。
- **成功收益**：得到“14 分钟静音段”和白檀移动主角的门轴声。
- **失败走向**：把循环雨声当作实时天亮前兆，开启 `false_dawn` 反向任务。

### 6.《假天亮》

- **触发语音**：“现在天亮了吗？”“拉开窗”“找月亮”。
- **前置**：夜间走廊或听见班车报站。
- **流程**：关闭月影投影，观察雨水仍在滴落；再听后山水泵，确认班车报站是预录。玩家若说“天还没亮”，记录 `false_dawn`。
- **成功收益**：钟楼血门和后山门都保留开放时间，G+S 可用。
- **失败走向**：相信假天亮只产生风险提示；你再次确认“现在独自离寺，不等他们”才结算 A/G-。结束确认前可返回熄投影、查水泵并救人，NPC 不因你问时间就被判遗弃。

### 7.《留守者的十四分钟》｜T13

- **触发语音**：“林岚，留在灯下完整复述广播”“保留原声，我去核对”“再听第三次回报”。
- **前置**：你已核验至少一名 NPC 并明确让其在大殿灯下等候；默认林岚。没有可用 NPC 时，随身录音机与大殿留声筒副本提供等价调查入口。
- **流程**：你独自探索，只听铜管回报；第三次回报插入14秒静默和伪造同伴声，并用“十四分钟”旧录残段诱导你。旧残段可完整回放，不能只凭任务标题推断缺口长度。你询问亲历的出门路线、比对桌铃近响与已保存原声，才能确认来源。镜头不切到留守者，14 秒干扰也不是整段 44 分钟昏迷的长度。
- **成功收益**：保存未剪辑回报，确认等候 NPC 的位置，保全铜印/红烛；为 S 的救援和时间证词提供佐证，不另设依赖多人配合的 R 结局。
- **失败走向**：误信假回报时出现失联待核标记；可返回灯台找副本，或说“停止追踪，复述最后原声”重查。不自动让主角进入 A，不删除线索。

### 8.《第零段录音》

- **触发语音**：“播放第三声前的静音”“倒放起始两秒”“我要听门轴声”。
- **前置**：`anchor_found` 加上杯沿或灯芯物证。
- **流程**：播放被剪掉的开头，听见白檀低声说“别让他在 23:00 前醒来”，随后是搬运枕头和门轴声。录音只能证明她参与布置，不能单独证明七年前的杀人。
- **成功收益**：开启白檀灯芯账的证人路线，尚不设置 `white_sandal_witness`；只有后续质询并取得完整未剪辑原录音才设真。
- **失败走向**：只凭录音指控白檀，触发“假清醒”分支，她烧毁一页证据；仍可走 G 或普通 S。

### 9.《白檀的灯芯账》

- **触发语音**：“白檀几点添油？”“把灯芯和时间对照”“请给未剪辑回答”。
- **前置**：得到剪短灯芯和三钟波形。
- **流程**：白檀先说“23:03 添油”。玩家指出灯芯蜡层在 22:46 已凝固，并要求她解释夹层卡死，她会停止篡改三十秒。
- **成功收益**：白檀交出未剪辑录音，设置 `white_sandal_witness`，公开顾惟真死于夹层的事实；H结局追加完整动机。
- **失败走向**：明确无证指认后白檀撕去一页复写副本，暂时停播；原始物证仍在，可用灯芯账与夹层重新质询，普通后山门与法华纸条路线不因一句话永久锁死。

### 10.《法华的第四夜复刻》

- **触发语音**：“对照第四夜档案”“为什么每次少十四分钟？”“把今晚钟声和旧档案对齐”。

- **流程**：当前钟声与旧档案拥有相同狗叫波形，却都缺失约 14 分钟。玩家说“有人把昏迷剪掉了”，法华回答“终于有人把钟外的时间带上来了”。
- **成功收益**：旧档案为事件排序提供独立佐证；`order_rebuilt` 仍须主角亲自排列当前夜事件才能成立。完成后G可强化，留烛救人时追加法华解脱录音。

## 七、分幕流程与主角可见的叙事

以下为相对游玩节奏，不是当前夜钟表真值。`script.md` 保持 001—054 场；分支回访在原场景编号下展开，不另插镜外 NPC 画面。

### 第一幕：旅行、失去意识与独自醒来（0—15 分钟）

你的视线从车窗移动到接待处和偏房；三位 NPC 通过走在你身侧、指物和与你对话建立关系。你陪同伴到门口记下三件私人物品与房间细节，吃过简餐，22:05再经香庭、四天王前厅与偏殿夜游。可上香或只观察，能听见猫鸟，见陆沉示范三敲，最后回到东院喝茶。

22:18 的失焦只给你能感到的杯响、铜铃、拖动与半句人语，随后黑屏；不展示白檀搬人的全景，也不给 NPC 集体投票交互。23:02 你独自醒来，先检查杯枕表、手机与假钟，发现缺口，再自己决定是否应门、出房。`gap_open` 在确认缺口后成立，恢复证词则需你后续主动反驳代签。

### 第二幕：三敲四敲、重新认识同伴（15—30 分钟）

你数完门响、查入住笔记、侧照影子，确认来者；误开可关门重查。到大殿后听三位 NPC 对“净化”各有态度：林岚要找原照片，周砚想先找出口，许栀担心拒绝会害大家。广播只向你索要自己的确认。你可以拒绝、要求原声、主动接受隔离，或暂时调查；不随机选玩家关入忏悔室。

调查长明灯、木鱼、铜管和忏悔孔均由你独立完成，NPC 可等候、扶灯、复述，但不构成谜题必需人数。香庭回访查烟向，前厅复原四天王方向牌，偏殿投三问；第三次后同姿石像必出现。NPC 情绪和神公答语给压力与方向，结论仍由主角提出。

### 第三幕：巨物过顶与被剪辑的声音（30—45 分钟）

你半夜进入大殿，灰从北梁落下，轰隆越过屋脊；你选择抬灯、听方向或退侧柱。随后以轨油/擦痕和水泵同步查明部分机械声，未知尾声保留。铜管完整遗言、两半铜印、四钟与重复雨声把调查引向旧案。

第二轮广播剪辑你已说过的话。你可要求前后句、指出同一段狗叫、拒绝指认；完成 `order_rebuilt` 则直接使假时序作废。你可让林岚在可返回的灯台留守，自己带录音机探索，T13 回报只在你耳边出现；失联不会切另一张画面，靠原声与现场标记找回。

### 第四幕：撞瓶、生死幡与密室还原（45—65 分钟）

你独自在方丈室外偷听白檀与陆沉谈先前代签，向前时碰落花瓶，必须用已埋线的猫叫或鸟鸣掩护；识别失败停追逼、澄清意图，真行动失败回前厅。成功保留“停滚架”与“幡文未烧”的原声，失败仍可取得等价物证。

你复原生死幡、撤销本人的伪同意；在场 NPC 自己发言，失联者保留未表态，不由主角替签。方丈室五证据由你排列；七年前 22:40—23:10 与当前夜分栏。NPC 可以应你要求出示图、照片与纸页，不替你把事件放上正确位置。质询“导师现在看见什么”暴露回放，灯芯账则揭出白檀的当前操控与七年前顾惟真死于夹层。

### 第五幕：深夜同行、法华与血门选择（65—85 分钟）

你决定独行或带已核验 NPC，假声只能用已录过的句子诱路；双线索身份核验可救回被引走者。找到宁秋水旧档案与法华纸条后，你持烛上钟楼，反转伪经并打开血门。

三盏引路灯显示本局累计仅容三人，回访不补名额。你可以确认自己先走（最多带两位 NPC），也可让三位 NPC 先走并留红烛接通真实后山方向，自己继续去回音壁。每次选择前明确显示谁已安全、谁仍待救、带走红烛的后果；不把某个 NPC 自动安排为牺牲者，不切镜追随离开的 NPC。你从栏窗和核验回报确认他们是否真的到安全点。

### 第六幕：主角的宣言与出口（85—100 分钟）

你先勘察往生廊，命 NPC 等在安全线，再独自试过危险段、逐人引导。广播催“一起喊、一起走”，但 NPC 不会替你无端集体冲刺；只有你在预警后明确选此指令才进入 B 回放。

铜印完整、至少三类证据和主角个人宣言可开普通出口。你亲手把印锁进卡槽，保存录音，决定继续救人还是确认离开；没人须永久留守。三位 NPC 已在灯路安全点时，你独过后山门会合；他们仍在寺中时，你可返回标记点救援。S/H/T 的强化都由你的一次清晰选择和已核验证据结算，NPC 的尾声对白只作回应，不要求第二位真人参与。

### 识别与容错

- 关键词只用于召回候选意图，最终由当前房间、已获得证据和上一轮动作共同判断。
- “如果”“是不是”等假设或含糊表达先澄清，不替玩家行动；“我不跟”“我拒绝指认”“我不让钟替我回答”等意图明确的拒绝正常执行并反馈，不能因有否定词而忽略。
- 语音不完整时，系统说“我只听见了前半句，请继续”，不增加压力。
- 请求超时或空回应时，系统说“这次回应没有传回来，当前状态未变；可以重试或复听上一句”，暂停危险计时，不提交选择、不扣压力。
- 纯静音不是回合，不写入投票、不扣压力。
- 录到回声或系统自己的 TTS 时，标记为回声，不作为玩家发言。
- 每个机关最多连续判错三次；第三次给出证据方向提示，再允许继续尝试。
- 披人皮和尚的身份判断必须至少满足两项证据，不允许单个关键词直接判定真假。
- “成佛”相关语句先判断玩家是在引用伪经、质疑伪经，还是提出反向解释；引用伪经不会被当作通关答案。
- “现在几点”只打开调查状态，不直接给出正确时间；玩家必须通过两件物证加一段环境或声纹证据校正。
- “我昏迷时同意了吗”始终明确回答“沉默不能算同意”，并提示查看醒痕与原始格；`witness_restored` 记录查证完成，不成为主角能否行动的前置。
- NPC 台词、寺内录音、TTS、回声和环境声不是玩家输入；NPC说‘我同意’只更新其剧情口供，不能触发主角投票、压力或结局。
- ‘停下/等我/跟随/逐人通过/出示物件’均有明确执行反馈；NPC缺席时提供主角独立完成的灯台、录音、门楔与地图入口。
- 动物声优先识别明确的伪装意图；不要求玩家模仿得像，不以口音、音高、音量或识别失败制造死亡。
- 门响必须播放完整一组并给复听入口；四敲不自动确证超自然，三敲不自动确认真人。
- 杯筊计次由动作与落定结果共同确认；重播对话、跑题或语音失败不会提前耗尽三问，第三投后遗漏线索可从底座补回。

### 声音作为证据的三种交互

1. **回放**：玩家说“再放一次”，可以听原片段，但不能直接获得结论。
2. **对比**：玩家说“比较第一声和第三声”，系统播放相同的背景狗叫和混响尾音。
3. **质询**：玩家问“你现在看见什么”，录音角色无法回答现场细节；玩家据此获得“非实时声音”证据。

## 九、结局分支

成功结局只在主角明确确认离寺后触发，先前查证与 NPC 状态决定可选项。B/C在触发时先中断为复盘节点，不能因证据多而覆盖失败；撤销失败来源后再继续判断成功结局。普通逃生不必救齐三 NPC；玩家也不能因某个 NPC 没说一句台词而被强制判成独逃。B/C 是可复盘失败，S/A/G 为路线结果，H/T 为可叠加的真相层；同一结果可呈 S+G+H+T，不按显示优先级吞掉已达成内容。

### S｜破誓：把声音还给所有人

条件：完整铜印、至少三类清醒证据、主角回音壁宣言通过、`seal_fixed`、`evidence_preserved`，且 `npc_safe_count=3`。铜印由你锁进自锁卡槽，主角可以自己最后通过，不需要真人或 NPC 永久留寺。三 NPC 可由你逐段引过后山门，也可先走血门三名额。至少四类证据，且拥有 `witness_restored`、`order_rebuilt` 并公开醒痕时升级 S+“四人全证人”；NPC 的证词由各自已核原句组成，不要求三位真人同时发言。

顾怀山原声：“钟声可以伪造，回声不会替你投票。”林岚把相机放低：“这次照片里终于有我们四个。”周砚：“门闩还抬着。没有人留在后面。”许栀：“回去以后，我们重新过这个周末。”若复原生死幡，各人带回自己的名签，陆沉说：“这次，没有一个名字是别人替你留下的。”画面始终由主角在出口回望、看到三人走入晨光后结束。

### A｜孤生：你选择先离开

条件：普通出口已验证可用，但你在明确看过 NPC 待救名单和证据状态后，仍选择取印或携现有副本独自离寺。尚可救援时系统先给“返回救援/确认离寺”选择；缺少一条支线、NPC 暂时失联或没有全员归队都不自动触发 A。

你走到寺外，镜头只看自己的湿手与身后未亮的灯。卡片写“你逃出去了，仍有声音留在门里”。NPC 的最终生死不靠镜外闪回定论。若你先带一至两名 NPC 离寺，则注明获救人数和未确认人数，A 作为救援未完成层保留；主角不被迫牺牲一个固定同伴。

若 `npc_safe_count=3`，但你在提醒后仍选择带走铜印或放弃保存原始证据，A 改为“全员生还，证据未竟”的缺憾尾声：三位同伴都在你眼前，卡片明确标出未保全的是持续开放的出口或原始证据，不播放有人被留在门内的台词。已满足的 H/T 仍可叠加，公开证据只按实际保存内容记录。

### B｜回放：把合声当成出口

条件：你在明确预警后命多人同时冲同一踏板，或明知声音被剪辑仍主动同意指认。NPC 自行恐慌、普通提问、语音失败与主角两只脚不会触发。

软箭音效、雾影和狂笑后退回上一安全节点，你保留物证、NPC 已知位置及本局 `cup_cast_count`。系统说明哪条指令导致回放，并开放分段通行或原声复核；不把现实操作失败写成角色死亡。

### C｜同化：让导师替你说完

条件：有效从众压力达到100，或你在三次明确澄清后仍主动选择“让导师替我决定”，或你主动承认昏迷沉默为有效同意且未在生死幡撤销。压力只由主角有效行为累计，NPC 的跟念、沉默与恐惧不算。`life_death_banner_restored` 可撤销代签来源，其他主动服从风险分别计算。

灯熄，喇叭用已经剪辑的主角声线说“我同意。我没有问题”。画面中的门没有打开。玩家可回证据节点重查，证据和三问次数保留；真正玩家静音、拒绝或求助不进入 C。

### H｜无声钟：识破循环

条件：任意五类证据；主角明确还原“顾惟真已死、白檀操控回放、沈墨未杀人”；双线索识破至少一次披皮伪装；`replay_proven` 与 `white_sandal_witness` 成立；终局主角拒绝替未发言者表态。

白檀当着你摘下变声喇叭的插头，交出顾惟真的最后手册。你选择“公开原始录音”则设 `evidence_published`，循环证据被保全；选择“仅自己带走”则保留私密真相尾声。是否救全 NPC 仍按 S/A/G 的实际结果结算，揭真相不能无条件让镜外所有人获救。

### G｜血门生还：让法华离开灯影寺

条件：主角持红烛与钟楼钥匙，完成身份核验，以纸条反转打开血门。本局累计最多三名角色通过，主角计一名；回访、折返或B/C复盘都不补已消耗名额，不能再开一轮送第四人。你可独自或带最多两名 NPC 先离寺，G记录血门生还；救援未完成则叠加 A/G-；尚未实际过门时可改选路线，已经过门的名额不退。未确认结束时可沿已验证回路继续救援，但只可使用剩余名额与后山门。

选择把红烛留在法华前并使用三名额送三 NPC 先行，你在栏窗亲见并核验安全回报，再独自完成后山门宣言；符合 S 条件则为 G+S。留烛不要求有人站在钟楼，也不消耗三名 NPC 中一人的生还资格。法华：“我没有成佛，但我终于能把自己的名字还给自己。”若主角没有确认离寺，未完成的救援和后山门仍可继续。

### T｜真时刻：把时间还给活人

条件：`gap_open`、`clocks_conflict`、`anchor_found`、`replay_proven`、`order_rebuilt` 与 `witness_restored`；主角保存并公开自身醒痕，至少三种独立时间来源写入记录，终局由主角一人说出“我醒来前已经被移动，第三声来自旧录音”。不要求另一名真人救回主角，不要求三 NPC 各讲一个通关句。

法华原声：“你不是错过了一个小时，是把被剪掉的时间还给了活人。”陆沉当面交出真实换班记录。T可叠加S/G/H/A的实际路线结果；恢复时间并不自动等于救齐同伴。若未留烛，法华停在“请把证据带出去”，主角仍按已核出口离寺。

## 十、单人运行与叙事规则

- 系统不直接给正确答案，NPC只提供自己知道的事实与可验证物件；推理、排序、路线和终局选择由主角完成。
- 可见画面与可听声源必须从主角当前位置成立；镜外行为只在你找到证据后回顾，不用全知分屏、上帝视角或切NPC操控补剧情。
- 昏迷黑屏只给短感知片段，醒后所有行动可独立开始；NPC可能不在身边，但关键解谜始终有主角道具途径。
- 每次错误都给一个可验证的新观察点：声音、灯芯、蜡屑、原始记录或夹层图，不能只说“你错了”。
- “暂停/退出游戏/我不舒服”优先作为安全意图：立即停追逼、静音威胁声，打开暂停与返回入口，不扣压力、不推进剧情。“开门”在求救语境触发安全流程，在普通门口调查时打开当前门；上下文不明先澄清。
- 定向耳语、低频与回放有独立音量和字幕；玩家可随时静音或重播，不以音量与听力门槛决定生死。
- 复盘先问“哪条证据改变了你的判断”，再问“哪句广播让你想跟随多数”。让玩家区分推理和服从，而不是把失败归因于听错一句话。

## 十一、关卡检查清单

### 推理闭环

- [ ] 玩家能从至少两条线索推出“钟声是回放”。
- [ ] 玩家能用停表、药碗、重复雨声和水钟把当前夜的事件顺序校正出来。
- [ ] 玩家能从蜡屑、铜丝、夹层图推出“门从外面反锁”。
- [ ] 玩家能从原始投票和补写笔迹推出“多数是伪造”。
- [ ] 陆沉、沈墨、白檀的口供在时间线上各有作用，不靠单句自白解决案件。
- [ ] 凶手身份、动机、手段和当前操控行为彼此一致。
- [ ] 主角的昏迷沉默始终不被真实规则当同意；代签只作为可撤销的反派伪造。
- [ ] 林岚/周砚/许栀均为NPC，所有关键任务一名真人可完成；缺席有物证补偿与救援入口。
- [ ] NPC台词、TTS和镜外动作不被当作玩家输入；压力与B/C只由主角明确有效行为结算。
- [ ] 血门最多三角色含主角；三NPC先走后主角继续后山门，留烛/留印均无需真人或NPC永久留守。
- [ ] 四天王造像、法器与真实方位正确，谜题只交换方向香牌，不要求损毁造像。
- [ ] 三次杯筊的形制、有效计次、固定答语和第三投变石像一致，漏听可补。
- [ ] 三敲与四敲有完整声音和双线索；三敲仍需身份核验，不能用敲击数跳过真假同伴。
- [ ] 屋顶巨响有轨油/擦痕及水泵同步两条机械线索，未知尾声不作通关条件。
- [ ] 生死幡本人声明，NPC缺席保留未表态也能完成复原；补救代签不抹除其他C来源。
- [ ] 猫鸟声和“只循人语”已提前埋线，花瓶支线可重试且不以语音识别失败判死。

### 语音闭环

- [ ] 每个机关有自然语言表达、可复听字幕与游戏内交互反馈，不依赖真人主持或线下器材。
- [ ] 否定句、疑问句、跑题和纯静音不会误触发机关。
- [ ] 识别失败会请求重说，不会静默丢弃或擅自扣压力。
- [ ] 玩家能要求重播、对比、质询，而不是只能猜关键词。
- [ ] 任何阶段能说“暂停/退出游戏/我不舒服”离开危险状态；普通“开门”与求救语境区分。
- [ ] 时间支线允许“现在几点”的调查，不把某个分钟数当作唯一答案。
- [ ] 失败支线保留已经获得的时间证据，并提供重新校准或救援入口。

### 情绪闭环

- [ ] 第一幕先建立与三NPC的旅行关系，再从主角自身记忆缺口制造不安。
- [ ] 第二幕让玩家体验“安静才看得见”。
- [ ] 第三幕让玩家听见自己的声音被剪辑。
- [ ] 第四幕用物证把恐惧转成推理。
- [ ] 第五幕让玩家在雨夜走廊判断同伴真假，并用红烛观察披人皮和尚。
- [ ] 第六幕要求玩家在钟楼血门前重新解释“成佛”，再在个人逃生和替别人留下出口之间做选择。
- [ ] 终局能区分 S、G、H、T、A、B、C 的条件组合，并明确是否有人被替代发言。
