# 《红烛无声》逐景实现索引

本表对照 `story/mini_script.md` 的 01—12 话，记录当前规则、分镜状态、人物构图、道具与声音的实际连接。`sceneKey` 是剧情场景，`shotKey` 是同一场景中的演出状态；同一房间的不同状态共享床、门、窗和矮桌的位置，再改变人物、烛光、道具与对白。

## 共同约定

- 新游戏由 `Engine.Initial → StartMiniStory` 建立 `mini_arrival / arrival_gate`，先显示开始界面与片头，再以大巴沿山路驶到午后山门的过渡镜头交代抵达。人物的话由该人物说，主角直接看到和听到的信息不进入对白。
- `actors` 保存姓名、角色、位置、动作、头像和可见性；前端依据这些状态画同行 NPC 并标记正在说话者。主角就是第一视角镜头，不绘制主角或未知占位；门外声源不隔门显示实体。转场与到达后的 NPC 按远近、步距和朝向错落站位，返程时陆沉留在寺门内。
- 道具由环境画面和微光热点共同呈现；鼠标或语音都把命令提交给后端，不在前端自行判定生死、吃粥或杯筊结果。
- 开启语音后，`dialogueNext` 只接续安全对白、已主动开始的经文和投掷后的结果。危险选择前会停下；主动作出调查也会打断接续。
- “重听当前对白 / 重听这句 / 再说一遍”只重播当前人物原句，保留原说话者；无人物对白时重听当前环境音，不补读环境描述，不推进分镜、经文、进食或投掷。
- 每句对白遵循“先看见—再动作—才开口”：先把镜头停在物件或声源上，完成一个可见动作，再播放与眼前所见有关的短句。角色说完后保留环境声间隔，等位置、光线或声源发生变化后才进入下一句。
- 直接可见、可听的事实由场景、道具近景、光影与有方位的环境音表达；观察更新 `sceneText / lastAction` 并清空人物对白，不进入人物或旁白 TTS。书页、残页、房牌和凭证的已知文字在物件视图中阅读。
- “你·心声”只保留少量真实感受、记忆与未证实的猜想，不复述刚呈现的事实或预先给出生存答案。主角实际念经使用“你”出声。危险判断、动物拟声、杯筊、开门和逃跑期间暂停自动对白，静音、识别失败和重听不推进危险状态。
- 未匹配剧情的有效发言进入在场 NPC 的独立问答，依据当前场景和最近问答回应；不知道就说明，意思不明才澄清。普通跑题不推进镜头、不扣虔诚度、不替玩家做用餐选择。空回答、超时和重复近期台词在播放、保存前拦截并明确反馈；无台词观察镜头不视为生成失败。

`sceneKey: mini_refectory`

| `shotKey`            | 画面与站位                                                               | 台词归属 / 操作                                        |
| -------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------ |
| `refectory_table`    | 林岚在桌左、周砚在对面、许栀在右，陆沉站在斋堂门边，慧普藏在右后帘内；粥、馒头、咸菜和本地素菜实际摆上桌 | 林岚、周砚、许栀讨论是否吃肉粥，提示主角逐一询问 |
| `refectory_porridge` | 四只带名签的碗各自保留进食状态；仅周砚碗切到勺底肉纤维调查态 | 周砚说明粥里似乎有肉，询问大家要不要吃；主线下一句由陆沉解释外客可自行选择 |

| `refectory_bread` | 许栀将馒头移近，示意咸菜、笋干和香菇青菜 | 不吃肉粥的人可以直接吃素食，不必等待住持回应 |
| `refectory_eating` | 四个人开始端碗；吃肉粥与吃馒头、素菜的动作同时保留 | 无提问时播放开始用膳；明确选择后按各人选择呈现，没人吃肉时由许栀说先吃素食 |
| `refectory_curtain`  | 帘后长明灯照出慧普半脸                                                   | 慧普亲口说“吃下我的，寺里会记得你”                     |

馒头、咸菜、本地笋干、香菇青菜、热水、施食记和四碗粥均有对应热点。主动查看粥碗以物件近景反馈，发现与解释由主线角色实际开口；不由主角心声或系统旁白重复说明。逐人讨论面板分别记录 `meal_<person>_ate/refused/deferred`，提到姓名、询问吃喝或喜好不会直接改变选择，明确吃馒头或素菜不记为喝肉粥；周砚单独接受吃粥前要求先看碗签。主角对同伴的询问和劝说会把玩家原话、最近问答和 NPC 性格送入 jev `systemone`，每位 NPC 返回 `refused/ate/deferred`；只有 `refused` 才设置不吃肉粥，并由该 NPC 附和“我也不吃肉粥了”一类自然短句。低置信度、超时或接口失败保留当前状态并让玩家重述。无提问时先播放 `refectory_eating`，明确选择但无人吃肉时由许栀说清改吃素食。

离桌时结算：四人全吃为 `meal_all_ate`；主角吃粥，或三位同伴都吃粥，会设置 `skin_double_present`。这些状态影响夜间真同伴、换皮来客及杯筊权重，不在此处提前揭示恶愿。若无任何选择，`refectory_eating` 默认让四人开始吃馒头和素菜，并由许栀说明不吃肉粥；若有明确选择但无人吃肉，也保留拒绝/暂缓并由 NPC 说清改吃素食。

## 06｜三更，熄灭的烛芯

`sceneKey: mini_wake_three_gongs / shotKey: wake_candle`

三声更锣在冷色门房响起；最后一声的震动先留在床板里，镜头再落到黑烛芯和黑红蜡泪。月光沿回廊移动，门外先有拖行声，停下后才传来刮门声；门外呼吸者不可见。“烛芯—月光—拖行—刮门”的顺序由画面与环境声完成，可逐项检查并重听，不由主角口述观察顺序。

“续燃红烛”恢复 `red_candle_lit` 并进入 07；明确选择不续燃才触发撞门死亡。静音、识别失败或没有输入不会自动判死。

## 07｜门内，完整的四敲

`sceneKey: mini_four_knocks / shotKey: four_knocks`

四下敲门完整播放，镜头留在门内；门外身份不明，不画出可辨认人物。可看门眼、门闩与门缝红蜡，由对应物件近景反馈；停顿、呼吸和笑声直接由环境音呈现，不朗读次数与声源结论。

“不开门并问是谁”先保留无人回应，再进入三敲场景；“开门”进入被剥皮同行人伸手入门的死亡反馈。“回答姓名”记录 `name_echo_heard`；有红烛可继续调查，无红烛则死亡。

## 08｜三敲，贴墙与剥皮现场

`sceneKey: mini_three_knocks → mini_listen`

| `shotKey`      | 画面与站位                                                               | 台词归属 / 操作                                              |
| -------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------ |
| `three_knocks` | 主角仍在门内；三声间隔完整，仅标明熟悉人声来自门外，不显示实体           | 对应同伴先提相机盖、修缮图或蓝发圈，再说所见；主角可核对身份 |
| `listen_door`  | 贴墙看半掩门，先看同行者房牌，再沿手电光看门；花瓶完整，真同伴站身后半步 | 同伴提醒别踩中砖；无人同行时仅保留脚步与门内声               |
| `listen_skin`  | 低沉念诵压过木板声；慧普的空背皮显露，床上显示实际受害同伴               | 手、皮与床沿动作直接呈现，不由心声、慧普或系统解释真相       |
| `listen_vase`  | 鞋跟碰倒花瓶，瓷片滚过地砖；慧普念诵停在半个音节，灯同时压暗             | 碎裂、停声和压灯直接呈现；停止自动对白，让玩家选择           |

真同伴按林岚、周砚、许栀顺序选择第一位未吃粥者；三人都吃则没有真同伴。进入偷听路线会先记录已听过猫叫与鸟鸣。房牌、手电、半掩门、花瓶、猫食碟、鸟笼均有调查命令。

- 模仿已听过的猫叫或鸟叫：记录 `animal_call_passed`，原路退回。
- 直接跑回房并关门：要求真同伴在场且红烛仍亮；缺任一条件会死亡。
- 跑向大殿：进入神公路线。
- 明确跑向后山、钟楼或陌生偏房：死亡。
- 退回后按 `skin_double_present` 进入 10，或直接进入 11；不会回到最初入睡前重复整夜。

## 死亡、重试与声音核验

- 死亡进入 `mini_death`，`shotKey=death_<来源 sceneKey>`，`retryScene` 记录来源。重试保留本局已学经文、调查、吃粥选择，清除失败和投掷等临时状态。神公失败特殊回退到已观察剥皮的 08；“重新开始”才建立全新山门开局。
- 固定语音角色为旁白、陆沉、主角、林岚、周砚、许栀、慧普、神公；门外假人复用所模仿者声音，角色配置保持独立。
- 环境观察与环境音不调用上述角色合成；旁白仅处理操作确认、输入澄清和失败原因。实际出声的四句经文使用主角音色与“你”姓名牌，少量内心活动才使用“你·心声”。
- 剧情规则回归在 `internal/game/story_storyboard_test.go`，覆盖逐句说话者、门外不可见、同伴与饭粥一致、先剥皮后碰瓶、四句经文、杯筊权重和安全重试、真五更后离寺。语音路由回归在 `internal/session/story_voice_roles_test.go` 与 `internal/integration/linx/voices_test.go`。
- 提交前运行架构检查、Prettier、前端测试、生产构建与 `go test -race ./...`。回归范围包含所有场景的未知问答不推进剧情、晚斋菜单和明确选择、同行转场、死亡重试、杯筊结果、换皮四句经文、道具交还与返程；同时核对无对白观察不生成 TTS、恢复存档不丢镜头和旗标。
- 实际页面验收须先通过实验 API 与像素绘制检查，再核对山门、登记、斋堂、回廊、房内书页/门闩、三更烛芯、四敲门眼、三敲、偷听和动物声调查的布局。隔离规则服务与流式 PCM 测试音频可验证状态和声音通路；真实麦克风、云端 ASR/TTS 需在实际设备另行验证，不与模拟音频验收混同。
