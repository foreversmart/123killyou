# 《红烛无声》逐景实现索引

本表对照 `story/mini_script.md` 的 01—12 话，记录当前规则、分镜状态、人物构图、道具与声音的实际连接。`sceneKey` 是剧情场景，`shotKey` 是同一场景中的演出状态；同一房间的不同状态共享床、门、窗和矮桌的位置，再改变人物、烛光、道具与对白。

## 共同约定

- 新游戏由 `Engine.Initial → StartMiniStory` 建立 `mini_arrival / arrival_gate`，先显示片头与开始界面，期间隐藏底部对白框，再以约 3 秒大巴山路远景和约 4 秒下车停门镜头交代抵达；山路与山门均使用实时 3D 摄像机衔接。下车停门镜头渐显时先播放林岚“坐了这么久的车，腿都麻了……终于到了。先下车活动一下”，对白框覆盖大巴画面；镜头结束并切入山门正片后，再继续其余四句对白。恢复存档只重听当前对白。人物的话由该人物说，主角直接看到和听到的信息不进入对白。
- `actors` 保存姓名、角色、位置、动作、头像和可见性；前端依据这些状态画同行 NPC 并标记正在说话者。主角就是第一视角镜头，不绘制主角或未知占位；门外声源不隔门显示实体。转场与到达后的 NPC 按远近、步距和朝向错落站位，返程时陆沉留在寺门内。
- 道具由环境画面和微光热点共同呈现；鼠标或语音都把命令提交给后端，不在前端自行判定生死、吃粥或杯筊结果。
- 开启语音后，`dialogueNext` 只接续安全对白、已主动开始的经文和投掷后的结果。危险选择前会停下；主动作出调查也会打断接续。
- “重听当前对白 / 重听这句 / 再说一遍”只重播当前人物原句，保留原说话者；无人物对白时重听当前环境音，不补读环境描述，不推进分镜、经文、进食或投掷。
- 每句对白遵循“先看见—再动作—才开口”：先把镜头停在物件或声源上，完成一个可见动作，再播放与眼前所见有关的短句。角色说完后保留环境声间隔，等位置、光线或声源发生变化后才进入下一句。
- 直接可见、可听的事实由场景、道具近景、光影与有方位的环境音表达；观察更新 `sceneText / lastAction` 并清空人物对白，不进入人物或旁白 TTS。书页、房牌和凭证的已知文字在物件视图中阅读。
- “赵熙·心声”只保留少量真实感受、记忆与未证实的猜想，不复述刚呈现的事实或预先给出生存答案。赵熙实际念经使用“赵熙”出声。危险判断、动物拟声、杯筊、开门和逃跑期间暂停自动对白，静音、识别失败和重听不推进危险状态。
- 未匹配剧情的有效发言进入在场 NPC 的独立问答，依据当前场景和最近问答回应；不知道就说明，意思不明才澄清。普通跑题本轮不改变镜头、不扣虔诚度、不替玩家做用餐选择。空回答、超时和重复近期台词在播放、保存前拦截并明确反馈，保留原有进度；无台词观察镜头不视为生成失败。
- 安全接话只限 `mini_arrival / mini_register / mini_refectory / mini_corridor_candle / mini_dawn`：原有 `dialogueNext` 是该场景的安全对白或既定转场，本轮由在场 NPC 回答且场景、镜头和面板未改变时，保留待续行。NPC 先简短回答本次发言，播放完成并等待后才继续原来的下一句或转场；连续发言重置等待。登记问“你是谁”、斋堂问“为什么有肉”等固定短答同样适用。没有待续行时不凭空开启，主动调查、歧义、缺席人物与危险段不恢复计时；回廊仍停在领烛前，天亮上车仍由玩家决定。

## 实时 3D 演出连接

- scene/world_view 挂载 WebGPU 画布；scene/renderer 按 Tidewater 的方式执行帧循环、材质着色、深度与阴影渲染，采用线性颜色、GGX、基础色/法线/ARM 贴图、叶片透明阴影与全景天空反射。resources.ts 读取本地素材，draws.ts 共享网格缓冲。
- scene/world/scene_state.ts 将原 sceneKey / shotKey 映射到山门、登记室、斋堂、回廊、门房、半掩偏房、偏殿、大殿与山路。placement.ts 保存米制空间中的机位、人物和道具锚点，热点由投影矩阵定位。
- scene/world_character 保持可动关节，使用 Rocketbox 解剖头模、游客衣褶与手部网格，僧人使用无帽头模、解剖手部和连续僧袍；肘膝采用连续混合变形，掌心锚点带动笔、餐具和烛台，坐姿不缩腿；对白栏的所有表情头像及云端音色保持原资源。actors.visible、帘后镜头、同行身份和换皮旗标控制实体显示。
- scene/world_environment/terrain.ts 构建连续地形，vegetation.ts/meadow.ts 放置 Poly Haven 近远树、苔石、蕨类和随风草地；doors.ts 建立门板、门轴、铜环和门闩；double_exit 保持关闭，double_frenzy 才抽闩并开门；statue.ts 挂载 Minneapolis Institute of Art 的 CC0 观音扫描和本作木石供座，保留原雕塑的面孔、手势与旧彩绘。roof_tile.ts 构建带厚度的阴阳瓦。昼夜全景跟随摄像机方向，假报晓保持夜景；来源见 assets/environment/README.md。
- world_character/performance.ts 按人物与分镜选择动作；day_actions.ts 处理书写、用膳、递烛、噤声和观察，night_actions.ts 处理伏身、延时回头、摸门闩、逐句减弱的抓挠和安抚伏地。cast.ts 负责行走位移与到站停步，performance_key.ts 避免保存、暂停或重听确认重播动作；renderer 更新掌心道具、灯光与脚底接触阴影。
- scene/world_prop 构建烛台、书册、钥匙、念珠、杯筊、碗勺、素菜、花瓶和鸟笼。烛光、各人空满碗、碎瓷、杯面和神公石化均读取已保存的后端旗标，不自行生成判定。
- scene/story_transition 沿用 3 / 7 / 4 秒等既定过渡时长，替换为回廊推进、大殿横移与人物步态；过渡期间不开放新的动作。scene/opening_journey 使用 3D 大巴与山路；原片头视频保留。
- 文字证据、原经文和死亡重试入口保留。实体物件的调查由 3D 摄像机靠近完成；书页文字和碗签另保留可阅读视图。
- 启动先实际验证 HTML-in-Canvas，再执行 WebGPU 三角形绘制与像素回读；失败时不加载游戏。运行中绘制失败会停止自动续行并提示重载，不显示静态替代场景。

## 03｜斋堂，肉粥与四人的选择

| `shotKey`            | 画面与站位                                                                                               | 台词归属 / 操作                                                                                |
| -------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `refectory_table`    | 林岚在桌左、周砚在对面、许栀在右，陆沉站在斋堂门边，慧普藏在右后帘内；粥、馒头、咸菜和本地素菜实际摆上桌 | 陆沉解释后留4秒劝素窗口；未及时劝素才触发同行者的肉粥宽慰                                      |

| `refectory_eating`   | 不论吃粥、拒绝、改吃素食或暂缓收束，四人统一连续约 5 秒端碗、夹菜、咀嚼和放碗；不显示同行者犹豫文字框    | 一名同行者说吃完并与众人收碗，陆沉随后直接带队回东院                                           |
| `refectory_curtain`  | 帘后长明灯照出慧普半脸                                                                                   | 仅主动看、听帘后或明确询问住持时，慧普亲口说“吃下我的，寺里会记得你”                           |

馒头、咸菜、本地笋干、香菇青菜、热水和四碗粥均有对应热点。主动查看粥碗以物件近景反馈，发现与解释由主线角色实际开口；不由主角心声或系统旁白重复说明。不显示逐人姓名与吃粥状态文字框；后端仍分别记录 `meal_<person>_ate/refused/deferred`，提到姓名、询问吃喝或喜好不会直接改变选择，明确吃馒头或素菜不记为喝肉粥；周砚单独接受吃粥前要求先看碗签。主角对同伴的劝说会把玩家原话、最近问答和 NPC 性格送入 jev `systemone`，每位 NPC 返回 `refused/ate/deferred`；只有 `refused` 才设置不吃肉粥，并由该 NPC 附和尊重寺庙、不吃肉的自然短句。低置信度、超时或接口失败保留当前状态并让玩家重述。集体劝素主要调整同伴：主角已有的吃粥、拒绝或暂缓选择保持不变，同句明确说“我吃肉粥”或“我也不吃肉粥了”时优先记录主角自己的选择；主角尚未选择时才随大家吃素，之后明确改口仍可重新选择。主角未选择时离桌会由陆沉澄清；同伴未选择时按暂缓记录。

晚膳主线先演 `refectory_porridge`、`refectory_lamp` 两句；解释结束后以 `自动继续晚膳讨论` 留出约 4 秒的语音窗口。未及时劝素才继续林岚、许栀的肉粥宽慰；每次接话前核对对应同伴的选择，已同意吃素者不再劝吃肉。全体劝素时将林岚、周砚、许栀分别作为 `meal_<npc_id>` 问题提交给 JEV；每个 NPC 都要依据自己的 `refused`/`ate`/`deferred` 结果单独回应，接受者说“入乡随俗吃素”一类的话，拒绝者说“既然有肉，为啥不吃？我吃了哈”一类的话，禁止以旧的统一念白代替。随后进入统一吃饭动画；没有新输入时完成讨论后正常收束，不自动替玩家喝肉粥。`meal_guest_explained` 记录供肉解释已经给出；`refectory_discussion_linlan`、`refectory_discussion_xuzhi` 和 `refectory_discussion_done` 记录讨论进度，避免恢复存档后重复接话。全体劝素进入用膳时同时收束介绍和讨论，后续接续不会重开劝肉对白。

离桌时结算：四人全吃为 `meal_all_ate`；主角吃粥，或三位同伴都吃粥，会设置 `skin_double_present`。无论选择吃粥、拒绝、改吃馒头咸菜本地素菜还是暂缓，先播放 `refectory_eating` 约 5 秒，斋堂全程隐藏逐人姓名、犹豫和选择状态文字框；动画末尾由同行者确认吃完，众人收碗后再自动进入回东院过渡。自动结束晚膳也使用相同结算：四人均未选择时统一记为 `refused`，设置 `meal_default_refused`，先吃馒头与素菜；已经有人作出选择时，已有 `ate/refused/deferred` 不覆盖，只在离桌时把其余未选择者记为 `deferred`。这些状态影响夜间真同伴、换皮来客及杯筊权重，不在此处提前揭示恶愿。

门房四项语音选择在按钮命令无法匹配、误落“没有交谈对象”或收到自然描述时，调用 JEV `systemone` 做一次四选一：`candle`（再看一眼烛火/查看烛芯）、`history`（翻翻寺史）、`scripture`（读一遍桌上的经书）、`sleep`（躺下歇一会儿）。点燃红烛仍由本地明确命令处理。请求携带玩家原话、当前场景和完整候选，JEV 只负责选择及置信度，本地规则负责执行镜头、旗标和转场。只有返回合法候选且置信度达到 0.55 时才执行；超时、错误、空答、低置信或未知候选均澄清并停留在 05，不创建交谈对象、不改变状态，也不以关键词命中替代四选一。

## 07｜门内，完整的四敲

`sceneKey: mini_four_knocks / shotKey: four_knocks`

四下更响的木门敲击完整播放，次数、间隔和敲后静默保持清楚，镜头留在门内；门外身份不明，不画出可辨认人物。可看门眼、门闩与门缝红蜡，由对应物件近景反馈；停顿与呼吸直接由环境音呈现，不朗读次数与声源结论。

“不开门”才立即进入三敲场景；确认空门后约 5 秒没有新操作，或重听四敲、保持安静后 5 秒没有新操作，也按不触碰门闩进入三敲。“不开门并问是谁”、喊话、回答姓名或任何其他隔门说话都保持对白栏空白，每句记录一次 `ghost_dialogue_started` 并扣 2 点虔诚度，仍停留在四敲场景。“开门”后只有鬼影冲入、地面出现血泊，进入统一死亡反馈；不再显示被剥皮同行人伸手、脸、身体或尸体。

## 死亡、重试与声音核验

- 死亡进入 `mini_death`，`shotKey=death_<来源 sceneKey>`，`retryScene` 记录来源；所有死亡分支保留来源场景环境，只表现鬼影冲入和随后出现的地面血泊，删除额外绘制的人形、角色身体、尸体与肢体。命中伴随低沉撕裂音效、黑红闪光、屏幕震颤，鬼影冲近后定格保留在左侧，地面为面积较小、分散且无高光/厚重投影的平涂血迹，右侧显示死亡结算卡；减少动态模式同样保留鬼影，卡片提供“从最近安全节点重试”和“从山门重新开始”。重试保留本局已学经文、调查、吃粥选择，清除失败和投掷等临时状态。神公失败特殊回退到已观察剥皮的 08；“重新开始”才建立全新山门开局。
- 打更使用清楚的金属锣音色，二更两声、三更三声、假报晓四声；假报晓余响结束后再播放一次远处钟声，钟与锣的音色可辨。真正五更保留五声更锣以及鸡鸣、檐鸟。四下敲门是独立事件，不是四更；全部敲门声保持木门质感、原有次数、间隔和静默。
- 固定语音角色为旁白、陆沉、主角、林岚、周砚、许栀、慧普、神公；门外假人复用所模仿者声音，角色配置保持独立。
- 环境观察与环境音不调用上述角色合成；旁白仅处理操作确认、输入澄清和失败原因。实际出声的四句经文使用主角音色与“赵熙”姓名牌，少量内心活动才使用“赵熙·心声”。
