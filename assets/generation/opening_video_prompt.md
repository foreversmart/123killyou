# 《红烛无声》片头：完整真人短片脚本与 Seedance 提示词

## 制作目标

一次生成18秒、横屏16:9的完整多镜头短片，统一真人演员、实景摄影、剪辑、配乐、人声与同期音效。情绪沿“贴门察看 → 察觉身后异常 → 被带着逃跑 → 失衡侧倒”发展。威胁留在画外，只制造疑问，不解释寺规、身世或游戏事件。

片头完全采用真人实拍电影质感；游戏本体继续使用既有二维美术。当前脚本已按场景参考与文字选角方式生成完整18秒原片：[播放片头](../video/opening/opening.mp4)。未作后期剪辑，等待用户检查。

## 人物、空间与光照

- 主角是摄影机背后的同一位成年男性，声音和呼吸在镜头附近；全程不展示他的脸或第三人称身体。运镜来自他转头、跟跑、失衡和侧倒。
- 唯一可见演员是林岚：约27岁的中国女性、黑色侧分短发、深色旅行外套、灰色内搭、相机与普通黑色旅行背包。身份、服装、相机与发型沿用参考图；不增加其他人物。
- 第一镜在客房门内，林岚在门边，主角在她身后略偏左；她转回头时越过主角，看到的是主角身后仍在画外的暗处。主角不回头揭示声源。
- 出门后始终沿同一条回廊前进：左侧木门与格窗，右侧木柱和开放庭院。第三、四镜方向一致，不换寺庙、不跳到另一条走廊。
- 室外为完全黑夜：天空、树冠、庭院与远处屋顶沉入近黑，仅烛火和少量暗黄廊灯照到的小片区域可读。图1保留一支燃烧红烛，不能把室外提亮成蓝色黄昏或亮月夜。

## 剪辑时长与转场

| 镜头       | 剪辑区间  | 起幅与落幅                                              | 台词                     |
| ---------- | --------- | ------------------------------------------------------- | ------------------------ |
| 1 贴门听声 | 约0–4秒   | 林岚侧脸、手与半掩木门 → 手指收紧，目光开始转回主角     | 男主角：“看到什么了？”   |
| 2 惊惧眼神 | 约4–7秒   | 两眼极近景 → 目光越过主角，短促后退                     | 林岚：“后面...后面！”    |
| 3 回廊逃跑 | 约7–11秒  | 主角被带进回廊 → 跟在林岚后一两步，继续向前             | 林岚：“跑！”             |
| 4 失衡落地 | 约11–15秒 | 延续同向奔跑 → 明确下降、侧倒、一次撞击，停到贴地斜视角 | 男主角：“拉我...”        |
| 5 毛笔片名 | 约15–18秒 | 纯黑中片名渐亮 → 片名稳定，女声与经声延续到结尾         | 疲惫女声：“快...快走...” |

上述区间包含转场，总片长18秒，不能在区间外另加黑场。时长用于控制剪辑节奏，人物动作按自然因果发展，不按细碎秒数摆姿势或等待。

四次转场围绕4、7、11、15秒发生：上一镜渐暗，短暂经过纯黑，下一镜渐亮。每次完整转场约半秒，黑底只短暂经过，几次过渡快慢相近。最后进入片名也沿用这一方式。画面未全暗前仍有动作；不定格、不硬切、不交叉叠化，不在黑场长时间等待。

每次渐暗开始时响起一声清楚、低沉、厚重的寺庙铜钟。钟声是转场时的声音重心，起音清晰，明显高于配乐与背景念经，余音自然衰减并跨入下一镜。前四镜的台词在各自镜尾钟声起音前完整说完；下一句在新镜头内进入，避开钟声最强的起音，不削弱钟声的存在感。

## 各镜执行细节

### 1 贴门听声

以图1锁定构图：林岚位于画面左中部，手扶右侧半掩的木门，前景左下是一支稍失焦的红烛；门缝外近黑，只见极弱廊灯。镜头是主角近距离所见，有呼吸带来的轻微起伏。

她先盯着门缝，再侧耳听。指尖在门边收紧，肩膀稍绷，嘴唇微张，呼吸放轻。男主角在镜头附近压低声音，略带害怕地问：“看到什么了？”尾音发虚。她没有立刻解释，目光先从门缝离开，开始转回主角。这个小反应把下一镜带起来。

### 2 惊惧眼神

渐亮时已经是图2的双眼极近景，两只眼睛和眉毛占满横幅，只留少量鼻梁，嘴不入画。不要先展示整张脸再慢慢找特写。

她的视线先接近主角，随即越过他，盯住他身后的画外位置；下眼睑绷紧，眉心收住，吸气短促。镜头有一次短而有力的小幅逼近，焦点跟住双眼。她微微后退，不能长时间保持同一个瞪眼表情。

林岚说：“后面...后面！”第一次像气息卡住，短暂停顿后第二次明显更急、更害怕。声音属于眼前同一演员；嘴留在画外，不为展示口型退成普通头像。男主角不回头，画面与眼中反射都不出现她看见的东西。

### 3 回廊逃跑

她抓衣袖、带主角出门的动作发生在上一镜末尾至转暗的衔接中，主要通过近处衣料牵动声与视线被带动表达。无需插入手部特写，不把复杂抓握、开门和奔跑挤在第三镜里。

本镜渐亮时两人已经进入图3的回廊。林岚领先一两步，主角被带着踉跄跟上；她回头一瞬，短促催促：“跑！”，接着转回前方继续跑。相机和背包随身体有惯性地摆动。

镜头保持成人眼高，以真实脚步带来上下起伏和轻微侧摆，主要朝前；近处木柱短暂掠过，局部运动模糊可以出现，主体空间仍可辨认。林岚自然跑向前方边缘，不凭空消失。落幅仍在前进，便于下一镜继续这个动作。

### 4 失衡落地

渐亮后承接同一回廊、同一方向的奔跑，不从平静站立重新开始。主角突然失去平衡，视线迅速降低，石地逼近，擦过右侧木柱边缘并侧向倾倒。

必须看见“高度下降 → 侧倒 → 一次撞击 → 短暂失焦 → 近地重新清楚”的连续过程。只跌倒一次，建筑不变形，不做完整旋转，不用站着随机摇晃代替摔倒。

落幅参考图4：镜头离石地约十厘米，明显倾斜，近处石纹与柱脚可读，远处灯光斜在边缘。林岚已跑到构图外，不展示主角身体。撞击截断男主角的喘息；缓过半口气后，他在镜头附近发颤地挤出：“拉我...”。留一个短暂、可读的贴地停顿，仍有微小身体余动与呼吸，不停成静帧。随后渐暗。

### 5 毛笔片名

贴地画面渐暗为纯黑后，按图5渐亮出现“红烛无声”四个简体字：暗朱红、粗粝厚重的手写毛笔字、干笔飞白与不齐笔锋，横排，四周留黑。标题出现后稳定保持，不逐笔书写，不加副标题、台词字幕、剧情标语或额外图案。

片名亮起后，近处传来一个疲惫女人的画外音：“快...快走...”。第一个“快”勉强挤出，短暂换气后再催促“快走”。虚弱而急切，声音真实，不尖叫、不扮鬼，不说明她是谁。省略号表示换气，不把停顿拖成长时间无声。话语在片尾前说完整，念经和寺钟余音延续到结尾。

## 声音连续性

- 全片只有上述五句普通话短句，每句对应一镜、只说一次。男主角第一和第四镜保持同一音色；林岚第二和第三镜保持同一音色。角色称谓和台词标点不读出来，不添加字幕或额外交谈。
- 众僧低声念经从第一帧到最后一帧持续，包括四次渐暗、黑场、渐亮与片名。是有真实寺殿混响、略有声部差异的男性群体齐诵；念经者不出镜，不承担剧情信息，不突然变成耳语、怪物吼声或解说。
- 配乐用克制低音与少量弓弦，随着人物受惊和逃跑收紧。台词、呼吸、衣料、脚步与撞击具有真实现场距离感；台词出现时轻轻压低配乐和经声，经声不断。
- 寺钟在每次转场清楚突出，起音厚重，明显在背景音之前；钟声混响自然跨镜。台词与钟声最强起音错开，两者都能清楚听见。
