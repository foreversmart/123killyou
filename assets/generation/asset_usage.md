# 当前素材用途

剧情以 [mini_script.md](../../story/mini_script.md) 的首夜十二幕为准。当前图片、真实尺寸、透明通道和校验值见 [素材目录](README.md)与 [asset_catalog.json](asset_catalog.json)；逐图提示词见 [完整流程制作清单](production_manifest.json)。不同动作、时段、机位和物品状态使用语义名称，每个状态只保留一个固定路径。

`assets/` 保存素材源图与组合配置，游戏从 `web/public/art/story/` 读取对应压缩素材，并依据后端场景、人物、道具和旗标决定显示状态。素材原图与组合配置已经接入剧情场景的运行时渲染；组合配置只负责裁切、比例、位置和遮挡，玩法状态仍由后端结算。语音分支、道具归属和存档不会由贴图层推断。组合预览只检查比例、位置和遮挡，不作为玩法状态源；当前运行时结构见 [演示素材说明](../../docs/design/assets-and-slicing.md)。

固定细节规范：后续生成或替换素材时，不需要随剧情状态独立变化的固定场景细节（门牌、牌匾、标牌及其准确文字等）直接画入图片，匹配材质、透视和光照；仅需随剧情变化、移动或交互的内容保留独立图层。沿用当前设定，不擅自更改无需替换的细节。

独处门房（含三更惊醒、敲门时与五更前等待）使用 room_seated_lit.png / room_seated_unlit.png 两张完整插画，主角独坐床边且窗外近黑；随红烛旗标整图切换，不再叠加人物、家具或桌面物件。门眼调查、同伴入室和死亡仍使用专用剧情画面，读书保留精确文字 UI。

## 人物和头像

## 接入和核对

1. 先按幕次选择机位和时段，再按各场景 layout 的 sourceFrame 取样、rect 等比缩放、zIndex 和 visibleWhen 组合。人物与道具不要整张透明画布硬塞进物体矩形。
2. 房位固定为近左“听”、远左“灯”、近右“门”、远右“纸”。半掩门使用同机位完整午夜底图，物品仍独立叠加；打开/关闭/花瓶状态不改房间拓扑。
3. 前景桌遮住人物下半身；门隙人物限制在主角可见区域。烛火、压灯、影子、呼吸参照、波形、折返与死亡淡出见 [scene_presentation.json](scene_presentation.json)。
   直接可见的物件和异常必须在对应画面或近景中可辨；敲门、钟锣、拖行、刮门、动物叫声等通过环境音呈现，不以主角心声、系统旁白或对白框复述。少量心声只表达真实感受、记忆和未证实的猜想。
4. 寺庙山门的主匾、旧匾、香客须知与接驳站牌文字直接绘入车内、下午及晨间背景；不在游戏内叠字。其余文书精确文本、镜面倒字与界面框由排版提供。书页、车票和预约单可复用纸面/文字视图，不额外编造可领取道具、皮号或镜外真相。
5. 源图和 WebP 运行素材保持同一路径映射，头像、物品、语音和保存恢复依照正式游戏链路验证；美术预览不绕过实验 API 实际能力检查。
6. 片头结束等待保留视频片名终帧，开始按钮放在标题下方；点击或语音开始后播放山路顶视远景约3秒、车内下车图约4秒并以柔和渐变淡入横移，门口停稳并切换山门外到达正片后，首句对白与完整字幕同步开始；片头和行程动画期间不显示底部对白框。“跟随陆沉进入东院”使用 arrival_walk_register.png 完整行进插画，陆沉持钥匙领路、三位同伴背向镜头跟随，门牌直接绘入；不使用普通回廊空景。其余场景转场以环境图与黑场衔接；经过大殿时使用巨大佛像与底部四名小比例人物统一绘制的阴森插画，连续约 4.8 秒并缓慢横向平移，不用正面站姿缩放、平移来模拟行走。
7. 拖痕、门闩湿痕和残缺影子分别使用 [drag_marks.png](../details/drag_marks.png)、[door_latch_wet.png](../details/door_latch_wet.png)、[broken_shadow.png](../details/broken_shadow.png) 物件近景，不用不相关的建筑或普通站姿图代替。
