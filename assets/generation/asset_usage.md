# 当前素材用途

剧情依据为 [mini_script.md](../../story/mini_script.md)。本表记录当前采用素材的用途；文件、尺寸与校验值见 [asset_catalog.json](asset_catalog.json)。当前共 29 张图片：四张场景背景、六张人物图、六张普通对话头像、一张未知人物占位头像、七张登记处透明图层、五张正式物品图。

这些素材尚未接入运行中的游戏；[网页原型素材与切图](../../docs/design/assets-and-slicing.md)记录当前演示所用文件。下表的幕次是计划使用位置，不代表对应分镜已经制作完整。登记处的坐标及状态切换已做素材叠加预览，游戏中的显示、领取和存档仍由后端真实状态驱动。

头像只表达玩家已看见的外貌。慧普第03幕帘后初见、外貌不可见或未核实的门外发言统一使用下述黑影加问号占位，保留头像框；不展示实际发声实体的面容。换皮者已露出熟悉面容时，应按玩家所见外貌选择头像，不能通过头像的有无或角色 ID 提前泄露真假。惊惧、拒绝、换皮和石化等表情/状态尚未制作，不能用普通头像代替已经揭露的异常。

当前前端对白栏使用独立方形图片，运行文件由角色头像 ID 映射；这批原图尚未接入，接入时输出所需网页格式并建立明确映射。当前演示的 keeper 头像继续属于演示角色，不自动等同于陆沉。已用 120px 小图核对脸部辨识、头顶留白和透明边缘；后续表情派生规范见 [portrait_prompts.json](portrait_prompts.json)。

## 未知人物占位头像

[unknown.png](../portraits/unknown.png) 是一张 1254 × 1254 的透明头肩黑影，由内置 image_gen 生成。它是通用界面素材，不对应新增 NPC；没有可辨五官、发型、僧衣或怪物特征。帘后与门外共用同一张图，不根据后台角色、真假、性别或年龄切换轮廓。

用于第03幕慧普帘后初见、第07/08幕尚未看清的敲门来者，以及第11幕门外诱导发言等场合。人物发言时继续占用与普通 NPC 完全相同的头像框、方形区域、边框和对白布局，不留空也不收起该列。系统旁白与纯环境声音沿用独立系统表现。

图片仅负责黑影。界面在脸部中央叠加准确的“？”，使用低饱和米灰色、克制暗影，不画发光眼睛或怪物提示。文字与边框不烘焙进 PNG；相对位置、字号与颜色见 [portrait_presentation.json](portrait_presentation.json)。

说话人名称只显示剧情已公开的称呼：未知时可用“帘后的声音”“门外的声音”；已知是住持但看不到面容时，可保留“住持（帘后）”。不要显示后台真实姓名。面容揭示后按玩家所见外貌选择普通头像；换皮者即使后台身份不同，也不能通过有无黑影提前泄露真假。

已在原头像框尺寸的素材预览中核对黑影与问号叠加；正式前端的头像映射、文字叠加和剧情状态仍待接入。当前图片与问号参数使用固定路径维护。

## 接入时如何查找

1. 先按本表确定幕次、时段和动作，再从 [素材目录](README.md)取固定文件；缺少的语义状态按表补制。
2. 登记处按 layout 的 sourceFrame 和 rect 组合，原始透明画布不能整张直接缩进道具矩形；其他场景尚无同等完整的分层配置。
3. 精确文字由排版提供；人物在场、道具归属和显示状态由后端结算。预览开关不作为正式玩法或存档结构。
4. 新素材接入网页前生成所需运行格式并更新消费引用；当前运行素材仍以演示切图链路为准，不能把“已出图”理解成“已在游戏中使用”。
