## 应保留的绘画特点

- 写实人体比例与二维叙事演出结合，人物五官有个体差异，避免精修人像式的统一漂亮脸。
- 深色细轮廓清楚，面部、衣领、手与道具的结构线有作用；不是把细节全部交给纹理与复杂明暗。
- 以较大的固有色色面和少量阴影交代形体，局部允许柔和渐变和轻排线；头发与衣服不逐根、逐皱高密度描绘。
- 纸与手绘质感轻而统一，木纹、墙裂和布料织纹保持稀疏。
- 夜景有明确色彩关系：可用青绿阴影、橙暖窗光和近黑前景，不把所有场景统一染成棕色。
- 恐怖主要来自日常空间、人物演出、停顿与少量异常；保持剧情证据物件清楚。
