# 正式物品图

五件物品供道具栏、背包与调查详情共用，使用内置 image_gen 生成；每张均为 1254 × 1254 的方形透明 PNG。人物、桌面和界面底色不包含在图中。

| 物品   | 文件                                        | 尺寸        | 用途与辨识点                                                                         |
| ------ | ------------------------------------------- | ----------- | ------------------------------------------------------------------------------------ |
| 铜钥匙 | [inventory.png](copper_key/inventory.png)   | 1254 × 1254 | 沿用登记处单枚钥匙的椭圆柄、短杆和齿口，物品图居中展示；右侧托盘的透视图继续独立使用 |
| 红烛   | [unlit.png](red_candle/unlit.png)           | 1254 × 1254 | 未点燃的粗短红烛，短黑烛芯与蜡面划痕；没有烛台、火焰或外部光晕                       |
| 念珠   | [inventory.png](prayer_beads/inventory.png) | 1254 × 1254 | 一串连贯的木念珠和短穗，右上方只有一颗明显更深的珠子；中间及珠间空隙透明             |
| 通行凭 | [inventory.png](permit/inventory.png)       | 1254 × 1254 | 完整浅米色通行凭；同一底图通过文字视图呈现正反面                     |

[显示与文字配置](../generation/inventory_presentation.json)按当前 itemId 记录物品图、显示范围和纸面文字坐标。按整张方形画布等比 contain 显示，避免裁掉钥匙齿、烛芯、珠穗或纸边；纸面文字层与图像一起定位。正式接入时应核对演示样式中的边缘渐隐遮罩与亮度滤镜，保持完整轮廓和当前色面。

通行凭正面排入“红烛寺”“通行凭”及暗红印记，背面排入“只许去，不许问”。这些文字由界面提供，底图不承担 AI 字形。通行凭正反面是同一纸张底图的排版视图，不新增并存图片副本。印记在登记交付后的正式凭证上呈现，登记桌上的空白纸张仍使用对应场景素材。

本批红烛仅表示未点燃；燃烧、熄灭和短芯等场景状态仍需独立制作。铜钥匙与通行凭的物品图是面向调查与背包的展示机位，不覆盖登记处的桌面透视图；它们在剧情里仍是同一件物品，归属由后端结算。

物品图片已输出为网页格式并接入剧情游戏，运行文件位于 `web/public/art/story/items/`，`internal/content/items.json` 使用对应路径。旧的 `/art/item-*.webp` 仅保留给非剧情演示；通行凭使用独立图片。六格道具栏的更多物品展示规则仍按游戏状态处理。

当前 [提示词](../generation/inventory_prompts.json)、[文件校验信息](../generation/asset_catalog.json)与[素材用途](../generation/asset_usage.md)使用固定路径同步维护。

## 首夜流程补充物件

火柴、手电、相机盖、折叠修缮图、蓝发圈夹纸、肉粥与食用后状态、木勺、馒头蒸笼、咸菜、香菇青菜、热水、腌笋、杯筊朝向与封存状态、鸟笼、猫食碟、花猫、麻雀和四只旅行行李已独立归档。房内经书、寺史册、未燃油灯与四种红烛烛台状态位于对应场景的 props/ 目录。

[逐幕素材用途](../generation/asset_usage.md)说明背包、场景与调查用途；[场景展示配置](../generation/scene_presentation.json)记录精确文字、归属与程序效果。场景图层按各 layout 的 sourceFrame 与 rect 组合；角色采用等比缩放。素材不会自行新增领取规则，状态与归属仍由后端结算。
